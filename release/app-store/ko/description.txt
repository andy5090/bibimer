내 손안의 에이전트 개발 환경.

Bibimer(비비머)는 프로젝트, Git 워크트리, 코딩 에이전트 세션, 대화, 터미널을 한곳에서 관리하는 ADE(Agent Development Environment, 에이전트 개발 환경)입니다. iPhone과 iPad에 포함된 Linux 해석기에서 프로젝트 파일과 개발 도구를 실행합니다. 별도의 개발 PC, 원격 개발 호스트, Termux 설치를 전제로 하지 않습니다.

실제 코딩 작업은 연결한 코딩 에이전트가 수행합니다. Bibimer는 세션을 관리하고 에이전트와 대화하며 작업을 확인하는 환경을 제공합니다.

프로젝트와 워크트리
프로젝트 폴더, 파일, Git 변경 사항을 살펴보고 프로젝트와 워크트리별로 세션을 정리하세요. 세션 이름을 바꾸거나 보관할 수 있으며 화면 이동을 작업 종료 요청으로 처리하지 않습니다.

대화와 터미널
지원되는 에이전트의 답변과 도구 활동을 구조화된 대화에서 확인하세요. 승인 요청에 응답하고 후속 지시를 대기열에 추가하며 저장된 대화를 다시 열 수 있습니다. 터미널에서는 명령과 대화형 도구를 사용합니다. 세부 기능과 호환성은 에이전트와 설치 버전에 따라 다릅니다.

개발 도구 연결
호환되는 Codex, Claude, OpenCode, Gemini CLI의 설치·계정 관리 흐름을 제공합니다. 본인의 제공자 계정이나 지원되는 API 설정으로 연결하세요. 모델과 추론 수준은 설치된 도구가 제공하는 목록을 사용합니다.

기기와 사용 방식에 맞게
10개 표시 언어, 메시지 입력 방식, 선택적 음성 입력·답변 읽기·완료 알림을 설정할 수 있습니다. 기기 권한과 선택한 서비스에 따라 동작하며 음성 인식 결과는 초안에 들어가고 직접 전송합니다.

사용 전 확인
개발 도구의 초기 준비와 에이전트 설치에는 인터넷 연결, 저장 공간, 시간이 필요합니다. 연결한 AI 서비스에는 별도 계정·구독이 필요하거나 사용 요금이 발생할 수 있습니다. Bibimer에는 AI 크레딧이 포함되지 않으며 제공자 구독을 판매하지 않습니다.

에이전트는 입력, 코드, 파일, 대화 맥락을 설정된 AI 제공자와 도구에 전송할 수 있습니다. 선택적 외부 음성 서비스는 사용자가 보내는 오디오나 텍스트를 처리합니다. 기기에 프로젝트 파일을 보관한다는 것이 AI 처리까지 오프라인이라는 뜻은 아닙니다.

iOS는 앱을 일시 정지하거나 종료할 수 있습니다. 백그라운드 실행과 알림 전달은 운영체제의 제약을 받습니다. 파일·저장 대화와 실행 중 프로세스는 구분하며, 유실된 터미널 출력이나 중단된 작업을 자동 복원·재전송하지 않습니다.

모든 Linux 패키지, 네이티브 확장, 브라우저 동작, 개발 환경과의 호환성을 보장하지 않습니다. Bibimer는 지원 에이전트·서비스 제공자와 독립된 앱입니다.
