Bibimer is an on-device Agent Development Environment for iPhone/iPad. It has no Bibimer accounts, registration, subscriptions or AI credits. Users install coding-agent CLIs and authenticate those tools with their own external provider accounts. Bibimer manages projects, Git worktrees, agent sessions, structured conversations and terminals.

Execution model
The app bundles an ARM64 Linux interpreter and Alpine base filesystem. Preparation downloads executable development packages from Alpine HTTPS repositories, including Python, Bash, Git, Node.js/npm and supporting tools/dependencies. Agent installation is a separate user action downloading the CLI/dependencies. These are executable tools, not static data. The app requests no JIT entitlement; Node uses the supported jitless configuration. We request review of this actual model without claiming an educational exception or blanket authorization under 4.7. Settings > Licenses and source provides GPL/third-party notices, corresponding source and build links.

Privacy and platform scope
Normal Chat/terminal and optional external voice/TTS actions have explicit app-styled disclosures and Allow/Cancel controls before the relevant operation. Settings can revoke sharing permissions. Provider recipients/terms apply; local files do not make AI processing offline. The work browser uses WKWebView with explicit project/browser control authorization; authentication uses a separate SFSafariViewController/native secure input. iOS can suspend/stop the app. Saved files/conversations persist separately from live processes; unlimited background execution is not promised.
