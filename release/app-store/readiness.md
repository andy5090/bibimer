# App Store 1.0.0 출시 준비

2026-11-18. 사용자 선택: **1.0.0 · 무료 다운로드 · 영어/한국어 등록 · 심사 승인 후 수동 공개**. 제출 자료와 출시 후보를 준비하는 작업이며 심사 제출·공개 완료가 아니다. 후보15는 App Store Connect 업로드·Apple 처리 후 버전 초안에 연결했으며 수출 규정 응답이 남아 있다. 국가는 중국 본토·프랑스를 제외한173개 지역으로 저장했다.

## 후보와 마지막 배포를 구분

- 마지막 확인한 내부 배포는 **TestFlight 0.1.0(14)**, 소스 `98138ae`다.
- 준비 대상은 **1.0.0(15)**, 소스 `7741191`. 에이전트 미선택 관리 진입·늦은 인증 URL 복귀 처리·검토된 Claude 복사 코드 수신이 추가됐다. 이 변경은 14번에 포함되지 않는다.
- 사용자는 14번에서 실제 iPhone Claude 로그인 성공을 보고했다. 15번의 새로운 복사 수신/붙여넣기 허용 동작까지 검증한 결과로 확대하지 않는다.
- iOS 16+, iPhone/iPad, 번들 ID `app.bibimer.ios`, App Store ID `6826729307`.

## 심사 정책상 확인 근거

Apple 2.5.2의 코드 다운로드·설치·실행 제한과 교육용 예외는 일반 ADE에 자동 적용되는 허가가 아니다. 4.7도 범용 Linux/CLI 전체의 허가로 해석하지 않는다. 해당 분류라면 호스트 API·소프트웨어별 데이터/권한 동의 조건을 함께 검토한다. 이 제품을 사실과 다르게 교육 앱이나 정적 데이터 뷰어로 소개하지 않는다. WebKit 기반 브라우저, 무료 보조 도구의 외부 계정·비용, 제3자 AI 동의를 실제 구조대로 설명한다. TestFlight 제공을 정식 심사 승인으로 표시하지 않는다.

근거: [Apple 심사 지침 2.5.2·2.5.6·3.1.3(f)·4.7·5.1.2(i)](https://developer.apple.com/app-store/review/guidelines/), [App Privacy](https://developer.apple.com/app-store/app-privacy-details/), [스크린샷 규격](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/) (2026-11-18 확인).

실제 제출 버튼을 누르기 전에 위 항목과 최종 스토어 화면을 다시 확인한다. `verification.json.submissionReady`가 false인 후보를 출시 완료로 표시하지 않는다.

## 이번 환경의 접근 제약

- 사용자 로그인 안내 뒤 App Store Connect에 접근했다. 기존 1.0 초안을1.0.0으로 바꾸고 무료 가격(미국 $0.00·한국 ₩0.00 포함175개 가격 통화)·수동 공개·영한 설명/프로모션/키워드/지원 URL·이름/부제·개발자 도구 카테고리·초안 심사 메모를 저장했다. 가격 통화 수는 출시 국가 선택 결과가 아니다. 국가 사용 가능 여부는 후속 작업에서173개 지역으로 설정했다. 연령·App Privacy·개인정보 URL·심사 연락처는 미완료다.
- 로컬 검증 환경에는 Simulator UI 앱 번들이 없어 화면 제어 도구로 촬영할 수 없었다. 자동 검증의 복구 뒤 화면은 마케팅 자료로 제외했다.
- Python HTTP/웹 읽기 도구에서는 공개 URL에 접근하지 못했으나 Chrome에서 한국어 개인정보처리방침·문의 양식의 정상 표시를 확인했다. 정책 본문은 실제로 Android·Termux·Android Keystore 중심이다. 지원 문의를 전송하지 않았다. iOS 정책 보완과 실제 기기 Safari 접근은 별도 확인이다.

## Console에서 추가 확인한 항목

- 중국 본토 배포에는 보안 평가·AIGC 서비스 신고/비안 관련 안내가 표시된다. 실제 서류/적용 여부가 확인되기 전 해당 지역 출시 완료로 표시하지 않는다. 중국 본토는 사용자 선택에 따라 출시 지역에서 제외했다.
- 연령 질문은 아직 입력하지 않았다. 현재 정의에서 제한되지 않은 웹 액세스는 앱 내 임의 페이지 탐색, 메시지/채팅은 사용자끼리의 직접 대화이며 AI 대화와 구분한다. UGC는 콘텐츠 배포 기능을 기준으로 검토한다. 특정 낮은 등급을 먼저 가정하지 않는다.
- 기본 설정에 Apple Silicon Mac/Vision Pro 사용 가능 체크가 있었으며 이번 작업에서 변경하지 않았다. iPhone/iPad 외 공개 범위와 실제 호환성은 별도로 확인한다.

## 최종 저장 재확인

새로고침 후 1.0.0·빌드15 연결·수동 공개와 기존 영어 등록 정보를 재확인했다. Console에는 3,396자의 이전 DRAFT 심사 메모가 저장되어 있다. 로컬 `review-notes.en.txt`의 첫 문장을 더 명확히 바꾼 3,426자 수정본은 필수 심사 연락처(이름·성·전화번호·이메일) 누락 오류로 저장되지 않았다. 저장되지 않은 수정은 새로고침으로 버렸으며, 연락처를 받은 뒤 로컬 수정본을 다시 저장하고 일치를 확인해야 한다. 심사에 추가/제출/공개는 수행하지 않았다.

## 제출 보류·스크린샷 우선 요청

사용자는 심사 제출을 아직 하지 말고 스크린샷 등 등록 자료를 먼저 갖추도록 명시했다. `심사에 추가`·심사 제출·공개는 새 명시적 지시 전 실행하지 않는다. 심사 연락처 이메일/국제형식 전화번호는 대화로 받았으나 Console에는 저장하지 않았다. 연락처 원문은 이 공개 저장소에 기록하지 않는다. Apple 공식 플랫폼 정보 안내에는 연락처 이름의 영문 필수 조건이 없고 심사 메모는 어느 언어로도 작성할 수 있다고 한다. 이름은 실제 계정 표기를 기준으로 확인한다.
