English
- Adds an isolated review workspace using fictional prerecorded examples. It does not run AI, execute the commands you type or access real project files. Review access requires the private code supplied separately for App Review.
- Adds explicit Allow/Cancel disclosures before normal agent, terminal and optional external voice data sharing, with permission revocation in Settings.
- Includes iOS GPL/third-party notices and corresponding-source links, and fixes the Korean file toolbar layout.
- Check project/session navigation, local terminal input, file views, agent account management, app return and reconnect behavior. External agents use your own provider account; provider fees may apply. iOS may suspend or stop live processes.
