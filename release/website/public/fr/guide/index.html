Premiers pas avec Bibimer

Vous avez besoin de Bibimer et de Termux sur le même téléphone Android. Termux exécute vos outils de développement et conserve vos fichiers de projet ; Bibimer réunit projets, sessions d’agents, conversations et terminaux dans une interface mobile.

Télécharger Bibimer sur Google Play

L’application et le site proposent dix langues. L’application suit la langue de l’appareil ; vous pouvez en choisir une autre dans les paramètres.

01Installer et ouvrir Termux

Installez Termux depuis l’une des sources indiquées dans son guide d’installation officiel. Ouvrez-le une fois et laissez la configuration initiale se terminer.

Installez Termux et ses éventuelles extensions depuis la même source de distribution. Aucun ordinateur de développement séparé n’est nécessaire pour suivre ce guide.

02Connecter Bibimer à Termux

Dans Bibimer, ouvrez Setup → Manual setup and pairing → Save setup file. Enregistrez le fichier sous bibimer-setup.sh dans le dossier Téléchargements d’Android.

Dans Termux, exécutez la commande suivante et accordez l’accès aux fichiers demandé. Ignorez cette étape si le dossier Téléchargements est déjà accessible.

termux-setup-storage

Exécutez ensuite :

bash ~/storage/downloads/bibimer-setup.sh

Le script prépare Python si nécessaire, installe le pont local Bibimer et le démarre. Saisissez le code à usage unique à 8 chiffres affiché dans Termux dans la section Connect this app de Bibimer. Le code est valable cinq minutes.

Si vous avez enregistré le fichier sous un autre nom ou dans un autre dossier, adaptez le chemin dans la commande.

03Ouvrir un projet et essayer le terminal

Ouvrez la barre latérale et choisissez Project Add. Parcourez les dossiers Termux ou saisissez un chemin tel que ~/projects/my-project et choisissez de créer le dossier si nécessaire. Enregistrez le projet.

Sélectionnez Terminal et démarrez une session. Saisissez cette commande et envoyez-la :

pwd

La sortie indique le dossier actuel de votre projet sur le téléphone. Cette première vérification ne nécessite aucun compte de fournisseur d’IA.

04Ajouter un agent de programmation au besoin

Préparez une installation compatible de Codex, Claude Code ou OpenCode dans Termux, avec la connexion au fournisseur ou la configuration API nécessaire. Choisissez ensuite l’agent dans Bibimer et démarrez une session.

Les modèles et options disponibles dépendent de l’agent installé. Les instructions générales d’installation Linux ne garantissent pas la compatibilité Android/Termux. Les tarifs et politiques de données des fournisseurs s’appliquent séparément.

Guide d’installation des agents dans Termux (en anglais)

05Organiser votre travail

Utilisez la barre latérale pour passer d’un projet, worktree Git existant ou session à l’autre. Chat affiche les réponses structurées et demandes d’approbation des agents compatibles ; Terminal propose leur interface en ligne de commande. Ouvrez l’explorateur de fichiers pour examiner les fichiers du projet, l’état Git et les modifications.

Changer d’écran ou fermer Bibimer ne demande pas l’arrêt des sessions. Android peut arrêter les processus en arrière-plan ; redémarrer le pont ne restaure ni les processus perdus ni leur sortie de terminal. L’archivage laisse le travail d’une session en cours.

Utilisez Settings → Language pour choisir la langue d’affichage de l’application. Votre saisie, les noms de projets et les sorties du terminal restent inchangés.

Nouveautés de la version 0.25.0

Version publique : 0.23.0. La 0.25.0 est proposée aux testeurs internes invités et a été soumise à l’examen de production.

Créez un worktree Git et une session depuis la barre latérale. Utilisez Steer pendant une réponse de Codex ou Claude, envoyez les messages en attente ensemble et utilisez Ctrl+Entrée pour envoyer si Entrée insère une ligne. Le blocage de l’écran de démarrage est également corrigé.

Dans la 0.25.0, Settings affiche les sessions actives de tous les projets, worktrees, archives et terminaux avant de mettre à jour ou redémarrer le pont. Confirmez leur arrêt ; la maintenance ne commence qu’après vérification. Les réponses en cours et les messages en attente peuvent être perdus ; la sortie PTY n’est pas restaurée. Annuler conserve les sessions. La création de worktrees et Claude Steer nécessitent le pont 0.18.0, à mettre à jour dans Settings. Supprimez les worktrees avec Git dans Termux. Maj+Entrée insère toujours une ligne ; Ctrl+Entrée l’insère si Entrée est configurée pour envoyer.

Besoin d’aide ?

Si la connexion échoue, vérifiez que Termux et le pont fonctionnent toujours. Indiquez l’étape atteinte et le message d’erreur lorsque vous demandez de l’aide. N’envoyez aucun mot de passe, clé API ou fichier de projet privé.
