作業環境を見てみる

会話、プロジェクト、ファイルをひとつに

実際の Bibimer 画面にサンプルのプロジェクトと会話を表示しています。個人のセッション記録は使用していません。

スマートフォンに、あなたのプロジェクト

プロジェクトファイル、Git、対応する開発ツールをスマートフォンの Termux で扱えます。別の開発用パソコンやリモートホストを用意せず、プロジェクトと既存のワークツリーを管理できます。

チャットとターミナル

構造化された会話とツールの動作を確認できます。指示の送信、承認リクエストへの回答、追加メッセージのキュー登録に対応しています。

使いたいエージェントを選択

対応する Codex、Claude、OpenCode を接続できます。インストールしたエージェントが対応するモデルやオプションから選択してください。

ファイルと Git の変更を確認

構文強調表示でコードを読み、Git の差分を確認できます。Markdown、静的 HTML、Mermaid 図のプレビューに対応。Office 文書、画像、PDF は対応する Android アプリで開けます。

まずは Termux から

Termux を使うと、Android で Git、Python、Node.js などを備えた Linux コマンドライン環境を利用できます。同じ端末にインストールし、Bibimer の準備ガイドに従ってください。まずはターミナルモードから始めましょう。対応するエージェントのインストールとプロバイダーの認証は別途必要です。

エージェントは、プロンプト、コード、ファイルを設定済みのプロバイダーやツールに送信する場合があります。料金や年齢要件は利用するサービスによって異なります。

Bibimer という名前について

Bibimer は、混ぜ合わせることを意味する韓国語の 비빔（bibim）に、接尾辞の -er を加えた名前です。Android アプリ、Termux、コーディングエージェントを混ぜ合わせ、ひとつの開発環境にするという思いを込めています。
