スマートフォンで、最初のプロジェクトを

Bibimer の使い方

同じ Android スマートフォンに Bibimer と Termux をインストールしてください。Termux が開発ツールを実行してプロジェクトファイルを保存し、Bibimer がプロジェクト、エージェントのセッション、会話、ターミナルをモバイル画面にまとめます。

Google Play で Bibimer を入手

アプリとウェブサイトは 10 言語に対応しています。アプリは端末の言語に従い、設定で別の言語も選べます。

01Termux をインストールして開く

Termux の公式インストールガイドに記載された配布元からインストールしてください。一度開き、初期設定が完了するまで待ちます。

Termux とアドオンは同じ配布元からインストールしてください。このガイドを進めるために、別の開発用パソコンを用意する必要はありません。

02Bibimer と Termux を接続する

Bibimer で Setup → Manual setup and pairing → Save setup file を開きます。Android の Download フォルダーに bibimer-setup.sh という名前で保存してください。

Termux で以下のコマンドを実行し、ファイルへのアクセスを許可してください。すでに Download フォルダーにアクセスできる場合は、この手順を省略できます。

termux-setup-storage

続けて、以下を実行します。

bash ~/storage/downloads/bibimer-setup.sh

スクリプトが必要に応じて Python を準備し、Bibimer のローカルブリッジをインストールして起動します。Termux に表示された8 桁のワンタイムコードを Bibimer の Connect this app に入力してください。コードは 5 分間有効です。

別の名前やフォルダーに保存した場合は、コマンド内のパスを変更してください。

03プロジェクトを開いてターミナルを試す

サイドバーを開き、Project Add を選びます。Termux 内のフォルダーを参照するか、~/projects/my-project のようなパスを入力してください。必要ならフォルダーを作成するオプションを選び、プロジェクトを保存します。

Terminal を選んでセッションを開始し、以下のコマンドを入力して送信してください。

pwd

スマートフォン内の現在のプロジェクトフォルダーが表示されます。ここまでの確認には AI プロバイダーのアカウントは不要です。

04必要に応じてコーディングエージェントを追加

Termux で動作する Codex、Claude Code、OpenCode を準備し、必要なプロバイダーへのログインや API の設定を完了してください。その後、Bibimer でエージェントを選び、セッションを開始します。

利用可能なモデルとオプションは、インストールしたエージェントによって異なります。一般的な Linux のインストール手順が Android/Termux でも動作するとは限りません。プロバイダーの料金とデータポリシーは別途適用されます。

Termuxのエージェントインストールガイド（英語）

05プロジェクトと作業を管理する

サイドバーで、プロジェクト、既存の Git ワークツリー、セッションを切り替えられます。Chat では対応エージェントの構造化された応答と承認リクエストを表示し、Terminal ではコマンドライン画面を利用できます。ファイルブラウザーを開くと、プロジェクトファイル、Git の状態、変更内容を確認できます。

画面を切り替えたり Bibimer を閉じたりしても、セッションの停止は要求しません。ただし Android がバックグラウンドプロセスを停止することがあります。ブリッジを再起動しても、失われたプロセスやターミナル出力は復元されません。アーカイブしたセッションの作業は継続します。

Settings → Language でアプリの表示言語を選べます。入力内容、プロジェクト名、ターミナル出力は翻訳されません。

0.25.0 の更新

公開版は 0.23.0 です。0.25.0 は招待された内部テスターに配信中で、製品版の審査に提出済みです。

サイドバーで Git ワークツリーを作成してセッションを開始できます。Codex・Claude の応答中に Steer で追加指示を送り、待機メッセージをまとめて送信できます。Enter が改行なら Ctrl+Enter で送信できます。起動画面が反応しない問題も修正しました。

0.25.0 の Settings では、ブリッジの更新・再起動前に全プロジェクト・ワークツリー・アーカイブ・ターミナルの実行中セッションを確認できます。確認したセッションの終了を検証してからメンテナンスを開始します。実行中の応答や待機入力は失われる場合があり、PTY 出力は復元されません。キャンセルするとセッションを維持します。ワークツリー作成と Claude Steer にはブリッジ 0.18.0 が必要です。Settings で更新してください。ワークツリー削除は Termux の Git で行います。Shift+Enter は常に改行し、Enter が送信なら Ctrl+Enter は改行します。

お困りですか？

接続できない場合は、Termux とブリッジが動作中か確認してください。お問い合わせの際は、進めた手順とエラーメッセージをお知らせください。パスワード、API キー、非公開のプロジェクトファイルは送らないでください。
