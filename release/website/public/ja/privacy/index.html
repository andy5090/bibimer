1. 利用目的と処理する情報

Bibimer は、同じ Android スマートフォンの Termux 内でプロジェクトやコーディングエージェントのセッションを管理するモバイルエージェント開発環境（ADE）です。プロジェクト名とフォルダーパス、セッションの識別子と設定、指示、応答、ターミナルやツールの出力、およびユーザーが扱うことを選んだファイルを処理します。これらの情報は、プロジェクトとセッションの表示、指示の送信、結果の表示、およびユーザーが要求した機能の提供に使用します。

Android のインターフェースは、同じ端末内の認証済みブリッジと通信します。アプリは設定と接続情報を専用ストレージに保存し、接続トークンは Android Keystore を使って暗号化します。Termux はプロジェクトとセッションのメタデータ、およびエージェントの記録を別途保存します。現在の Android アプリには広告・解析 SDK はなく、会話を Bibimer が運営するサーバーにアップロードする機能もありません。

審査用デモへのアクセスには非公開コードが必要です。入力されたコードは端末内で検証され、保存されません。デモモードは、メモリ内の架空のセッション記録を再生します。チャットやターミナルへの入力は用意された応答に影響せず、サンプル記録にも保存されません。デモの再生では、エージェントやコマンドの実行、プロジェクトファイルへのアクセス、プロバイダーへの接続は行いません。デモの設定は個別に保存され、終了時にサンプルワークスペースがリセットされて通常の設定に戻ります。このプライバシーポリシーを開く操作を選ぶと、ブラウザーが起動する場合があります。

2. コーディングエージェントと外部サービス

指示を送信すると、選択したエージェントがプロンプト、コード、ファイル、会話の文脈、ツールへのリクエストを、設定済みの AI プロバイダーやその他のサービスへ送信する場合があります。処理と保持の方法は、使用するエージェント、プロバイダー、アカウント、権限、設定によって異なります。ローカルのブリッジ接続であっても、AI 処理が端末内で完結するとは限りません。

別のエージェントで会話を続けることを選んだ場合、確認して送信した文脈はそのエージェントに渡され、記録に保持される場合があります。また、ツールのインストールやリンクを開く際には、Termux、パッケージリポジトリ、開発ツール、外部ウェブサイトもリクエストを処理します。選択したサービスのポリシーを確認してください。

3. GitHub とファイルを開く機能

GitHub からのインポートは、Termux 内の GitHub CLI を使用して認証、アクセス可能なリポジトリの一覧取得、選択したリポジトリのクローンを行います。認証情報は GitHub CLI が Termux 内で管理します。Bibimer はアカウントの状態、リポジトリ情報、必要な場合の一時ログインコードを表示しますが、認証トークンを WebView や通常のログには送信しません。クローンしたファイルは選択したフォルダーに残ります。

プロジェクト内または Download フォルダー内のファイルを別の Android アプリで開くと、Bibimer は専用キャッシュに一時コピーを作成し、選択したビューアーに一時的な読み取り権限を付与します。その後、ビューアーは自身の方針に従ってファイルを処理します。そのコピーを編集しても、元のプロジェクトファイルは変更されません。キャッシュにはサイズ上限と有効期限があり、その後のアプリ使用時や接続解除時に削除されます。

4. 通知と権限

通知の権限と応答監視が有効な場合、完了通知にプロジェクト名、セッション名、完了した応答の最大 180 文字が含まれることがあります。ロック画面の公開表示には、一般的な完了メッセージを使用します。Android の通知設定や通知へのアクセス権を持つ他のアプリは、通知内容を見られる範囲に影響します。設定画面または常駐通知から監視を停止できます。

Termux のコマンド実行には、Android の権限許可と Termux の外部アプリ連携設定が必要です。Bibimer はその権限を、ユーザーが要求した設定や開発操作に使用します。応答完了のプレビューは、ブリッジのメタデータファイルや通常のログには保存しません。

5. 保持、削除、管理

アプリの設定と接続情報は、アプリのデータを消去するかアンインストールするまで保持されます。ブリッジの最近の出力とキュー内のメッセージは実行中のセッションのメモリに限られ、プロセスの終了やブリッジの再起動で失われる場合があります。Termux のプロジェクトファイル、セッションのメタデータ、エージェント本来の記録は別途保存され、その保持期間はユーザーの操作やエージェントの保持設定によって異なります。

Bibimer の一覧でプロジェクトの登録を解除したり、終了済みセッションを削除したりしても、削除されるのは Bibimer の登録情報だけです。プロジェクトフォルダー、Git ワークツリー、エージェントの元の記録は削除しません。それらのファイルや記録は Termux と該当エージェントで削除してください。Bibimer をアンインストールしても削除されません。プロバイダーが保持する情報の削除は、そのプロバイダーに直接依頼してください。

Bibimer 独自のユーザーアカウントは作成しません。GitHub と AI プロバイダーのアカウントは各サービスが管理します。アプリ内で Bibimer とローカルブリッジの接続を解除でき、外部サービスへのアクセスは該当するサービスやツールで取り消せます。

データの削除や削除方法の案内を依頼する

  1. 件名を Bibimer data deletion として、andy@andineering.com にメールをお送りください。
  2. アプリの設定、Termux のファイル、エージェントやプロバイダーの記録、過去のサポートメッセージのうち、どれに関する依頼かをお知らせください。パスワード、API キー、非公開のプロジェクトファイルは送らないでください。
  3. Andineering は、サポートのやり取りなど当方が保持する情報に関する依頼に対応し、ローカルデータの削除方法を案内できます。Termux のプロジェクトファイルやエージェントの記録のコピーは保持していません。それらは端末上で削除し、プロバイダーが保持するデータは該当プロバイダーに直接削除を依頼してください。

ローカルデータは、上記の方法で削除するまで残ります。外部プロバイダーの記録の保持期間は各プロバイダーが定めます。サポートのやり取りは、依頼への対応や適用される法的義務の履行に必要な期間のみ保持します。同じメールアドレスから削除を依頼できます。

6. 対象年齢

Bibimer は 13 歳以上を対象としています。外部エージェント、プロバイダー、開発サービスには独自の年齢・アカウント要件があり、より高い年齢が必要な場合があります。

7. ウェブサイトのホスティング

このウェブサイトは Cloudflare Pages でホストしています。Cloudflare はウェブサイトの配信と保護のため、IP アドレスや通信データなどのリクエスト情報を処理します。そのインフラでは、情報が国外で処理される場合があります。詳細は Cloudflare のプライバシーポリシーをご覧ください。この静的サイトには、Andineering が追加したアカウント機能、問い合わせフォーム、広告、解析スクリプトはありません。選択した言語を記憶するため、ブラウザー内に言語設定を保存します。

8. お問い合わせと変更

プライバシーに関する質問や、情報へのアクセス・訂正・削除の依頼は、上記の連絡先にお送りください。お問い合わせ時には、回答と解決のため、メールアドレス、メッセージ、添付ファイルを処理します。依頼に必要な情報のみをお送りください。アプリにおけるデータの取り扱いが変わった場合は、本ポリシーと施行日を更新します。
