This policy covers Bibimer for Android and iOS. The iOS-specific details below explain the differences from the Android and Termux features described in sections 1–5. Website, inquiry and age provisions apply to both versions.

Bibimer on iPhone and iPad

The iOS app (app.bibimer.ios) runs a Linux environment inside its own app container; it does not require Termux. Project files, session metadata and agent records are kept in that environment, and app preferences are stored privately on the device. Local storage does not mean that connected AI services process data offline.

Connected coding agents can send your instructions, conversation context, code, files and tool requests to their configured providers and other tools. Provider account identifiers and authentication data are processed when you connect an account or API. Recipients, processing, retention and possible use for model improvement depend on the provider, account, permissions and service settings. Review the app’s data-sharing information before allowing AI features. Commands and external tools you run can make their own network requests.

Provider sign-in can use a native Safari authentication view and native secure code or key entry. Only during a supported Claude manual-code sign-in that you start, while that authentication view is visible and the app is active, can the app read a newly copied authentication code. It validates the current challenge before submitting it once through the native sign-in path. iOS controls paste permission; manual secure entry remains available. Secret values are not returned to the app’s web interface or ordinary logs, and the app does not clear your clipboard. Agent credentials follow the chosen CLI’s storage rules inside the app environment.

Optional iOS speech input uses Apple Speech or your selected API provider. Apple Speech may use Apple’s network services. External transcription sends your recording to OpenAI or ElevenLabs after the recording and transmission-confirmation flow. Read-aloud uses the device voice or ElevenLabs; external read-aloud and voice previews send the chosen answer or locally extracted summary text to ElevenLabs. Transcripts enter a draft and are not sent as agent messages automatically. Provider charges and retention terms depend on your account and configuration.

Voice API keys are stored in iOS Keychain and can be removed in Settings. Temporary recordings and playback files are removed after completion, cancellation or failure; leftover voice files are cleaned at the next app start. Local summary extraction does not make an additional model request. Removing a local key or temporary file does not erase audio or text already received by a provider.

The separate work browser uses WKWebView and keeps website data in the app’s browser profile. Websites you open can process requests, cookies and account data under their own policies. Agent screenshot and scroll access requires permission for the relevant project/browser run; a permitted screenshot can expose the visible page to that agent and its configured services. The native authentication view is separate from this agent browser control.

iOS completion notifications use a general completion message. Display and background delivery depend on device permission and operating-system limits. Optional debug diagnostics are off by default and keep only a bounded local history of fixed status events and numeric or Boolean values when enabled. Turning debugging off clears that history; the app does not upload it automatically. Copies or support inquiries you choose to send follow the inquiry provisions below.

Removing a project registration or an ended session from the list does not delete its project files, Git worktrees or original agent records. Delete those files in the app’s local Linux environment when intended. Removing the iOS app removes its local container, subject to device backup and restore settings; unlike separate Android Termux storage, this container belongs to Bibimer. Remove voice keys in Settings and use the external provider’s controls to revoke access or request deletion of provider-held data. Do not include passwords, API keys, sign-in codes or private files in support inquiries.

Policies and service terms of the selected recipients apply, including their regional and account-specific versions: OpenAI, Anthropic, Google, ElevenLabs, Apple.

1. Purpose and information processed

Bibimer is a mobile agent development environment (ADE) for managing projects and coding-agent sessions in Termux on the same Android phone. It processes project names and folder paths, session identifiers and settings, instructions, responses, terminal and tool output, and files you choose to work with. This information is used to display your projects and sessions, send your instructions, show results, and provide the features you request.

The Android interface communicates with an authenticated bridge on the same device. The app stores preferences and connection information in its private storage, with the connection token encrypted using Android Keystore. Termux separately stores project and session metadata and agent records. The current Android app has no advertising or analytics SDK and no feature that uploads your conversations to a Bibimer-operated server.

Review demo access requires a private code, verified locally without retaining the submitted code. Demo mode replays fictional sample session logs from memory. Chat and terminal input do not affect the prepared responses and are not retained in the sample records. Demo replay does not run agents or commands, access your project files, or contact providers. Demo preferences are stored separately; exiting resets the sample workspace and returns to your normal settings. Opening this privacy policy may launch your browser if you choose it.

2. Coding agents and external services

When you send an instruction, the agent you select may transmit prompts, code, files, conversation context, and tool requests to its configured AI providers and other services. Processing and retention depend on the agent, provider, account, permissions, and settings you use. A local bridge connection does not mean that AI processing stays on your device.

If you choose to continue a conversation with another agent, the context you review and send is delivered to that agent and may be kept in its records. Termux, package repositories, development tools, and external websites also handle requests when you install tools or open their links. Check the policies of the services you select.

Optional voice features use the device speech app or your chosen API provider. For API speech input, you record audio and confirm before sending it to OpenAI or ElevenLabs for transcription. Read-aloud is off by default; if enabled, Android TTS or ElevenLabs reads the selected answer or summary. External read-aloud and voice previews send the text to ElevenLabs. Device speech apps and Android TTS may also use the network. Provider fees and data retention policies apply; Bibimer does not automatically switch providers after a failure.

Voice API keys are encrypted with Android Keystore on this phone and can be removed in Settings. Keys, recordings and synthesized audio are not sent to Termux or Bibimer servers or stored in ordinary logs. App-private temporary recording and playback files are deleted after completion, cancellation or failure; crash leftovers are cleaned on the next app start. Read-aloud summaries extract key sentences on the device without an additional model request. Transcripts enter your draft and are not sent as chat messages automatically; text you later send follows normal conversation storage rules.

3. GitHub and opening files

GitHub import uses GitHub CLI in Termux to authenticate, list repositories you can access, and clone the repository you select. GitHub CLI manages its credentials in Termux. Bibimer displays the account status, repository information, and a temporary sign-in code when needed; it does not send the authentication token to its WebView or ordinary logs. Cloned files remain in the folder you select.

When you choose to open a project or Download file in another Android app, Bibimer creates a temporary copy in its private cache and grants the selected viewer temporary read access. The viewer then processes the file according to its own practices. Editing that copy does not change the original project file. Cached copies are subject to size limits and expiry and are cleaned on subsequent app use or disconnection.

4. Notifications and permissions

With notification permission and response monitoring enabled, completion alerts can include project and session names and up to 180 characters from the completed response. The public lock-screen version uses a general completion message. Android notification settings and other apps with notification access can affect who can see notification content. You can stop monitoring in Settings or from its ongoing notification.

Termux command access requires your Android permission and Termux external-app settings. Bibimer uses that access for the setup and development actions you request. Completion previews are not stored in bridge metadata files or ordinary logs.

5. Retention, deletion, and control

App settings and connection information remain until you clear the app's data or uninstall it. Recent bridge output and queued messages are limited to the running session's memory and may disappear on process termination or bridge restart. Termux project files, session metadata, and native agent records are stored separately; their lifetime depends on your actions and the agent's retention settings.

Removing a project registration or deleting an ended session from Bibimer's list removes only its Bibimer registration information. It does not delete project folders, Git worktrees, or original agent records. Use Termux and the relevant agents to delete those files and records. Uninstalling Bibimer does not remove them. Request deletion of provider-held information directly from that provider.

Bibimer does not create a separate Bibimer user account. GitHub and AI provider accounts are managed by those services. You can disconnect Bibimer from the local bridge in the app and revoke external service access using the relevant service or tool.

Inquiry information

Inquiry database records, including the message and optional reply email, are regularly deleted after 90 days from submission. Private support notifications for inquiries submitted from November 3, 2026 follow the same schedule. Failed deletions are retried; earlier notifications and notifications without a saved deletion identifier require separate cleanup.

Andineering does not hold copies of your Termux project files or agent records and cannot remotely delete data on your device.

6. Age range

Bibimer is intended for users aged 13 and older. External agents, providers, and development services have their own age and account requirements, which may be higher.

7. Website hosting

This website uses Cloudflare Pages, Pages Functions, and D1. Cloudflare processes request information, including IP addresses and traffic data, to deliver and protect the site, and may process it internationally. Our inquiry service stores a keyed digest of the IP address only to limit abuse, not the raw IP address. The site has no login, advertising, or analytics script added by Andineering; your chosen language is saved in your browser. See Cloudflare’s privacy policy.

With consent before submission, the contact form stores the category, custom topic, message, optional reply email, language, submission time and reference to handle the inquiry. Email is optional and used only to reply. The message and optional email are also forwarded as a private support notification; external processing services may use infrastructure outside your country. See the support notification service privacy policy. No login or attachments are required. App conversations are not uploaded automatically. Do not put personal information in the message.

8. Contact and changes

For requests about a submitted inquiry, use contact form and include its reference if available. You can also contact andy@andineering.com. Direct email correspondence is kept while needed to handle the inquiry.
