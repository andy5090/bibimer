Android + Termux

你的手机。
你的开发环境。

让 Android 手机成为你的开发环境。Bibimer 是一款移动智能体开发环境（ADE），通过同一部手机上的 Termux，将项目、编程智能体会话、对话和终端整合在一起。

在 Google Play 下载 BibimerGitHub 仓库

免费 · Android 8.0 及以上 · 与 Termux 安装在同一部手机上

本网站提供简体中文版本。当前 Google Play 应用支持英语和韩语；更多应用语言正在准备中。

在手机上管理你的项目

项目文件、Git 和兼容的开发工具都在手机上的 Termux 中运行。无需额外的开发电脑或远程主机，即可管理项目和已有的工作树。

对话与终端

查看结构化对话和工具活动。发送指令、处理审批请求，并将后续消息加入队列。

自由选择智能体

连接兼容的 Codex、Claude 和 OpenCode 安装版本。选择已安装智能体所支持的模型和选项。

查看文件与 Git 更改

通过语法高亮阅读代码，查看 Git 差异。预览 Markdown、静态 HTML 和 Mermaid 图表。使用兼容的 Android 应用打开 Office 文档、图片和 PDF。

从 Termux 开始

Termux 为 Android 提供 Linux 命令行环境，可运行 Git、Python、Node.js 等众多工具。请将它安装在同一部手机上，并按照 Bibimer 的设置指南操作。可以先使用终端模式；兼容智能体的安装及服务提供商的身份验证需要另行完成。

智能体可能会将你的提示词、代码和文件发送给其配置的服务提供商和工具。费用与年龄要求取决于你使用的服务。
