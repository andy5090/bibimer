0.25.0 更新

当前公开版本为 0.23.0。0.25.0 已向受邀内部测试者提供，并已提交正式版审核。

从侧边栏创建 Git 工作树并启动会话。Codex 或 Claude 响应时可使用 Steer 追加指示，将排队消息合并发送；Enter 为换行时，可用 Ctrl+Enter 发送。此版本也修复了首屏卡住的问题。

0.25.0 的 Settings 会在更新或重启桥接服务前显示所有项目、工作树、归档和终端中的运行会话。确认后结束列出的会话，验证进程确实结束后才开始维护。正在生成的响应及排队输入可能丢失，PTY 输出不会恢复；取消可保留会话。创建工作树和 Claude Steer 需要桥接版本 0.18.0，请在 Settings 更新。删除工作树仍使用 Termux 中的 Git。Shift+Enter 始终换行；Enter 设为发送时，Ctrl+Enter 换行。

从 Termux 开始

Termux 为 Android 提供 Linux 命令行环境，可运行 Git、Python、Node.js 等众多工具。请将它安装在同一部手机上，并按照 Bibimer 的设置指南操作。可以先使用终端模式；兼容智能体的安装及服务提供商的身份验证需要另行完成。

智能体可能会将你的提示词、代码和文件发送给其配置的服务提供商和工具。费用与年龄要求取决于你使用的服务。

为什么叫 Bibimer？

Bibimer 由韩语 비빔（bibim，意为“混合”）加上后缀 -er 组成。这个名字表达了将 Android 应用、Termux 和编程智能体融合在同一个开发环境中的想法。
