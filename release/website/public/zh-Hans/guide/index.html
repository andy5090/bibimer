在手机上开始第一个项目

开始使用 Bibimer

请在同一部 Android 手机上安装 Bibimer 和 Termux。Termux 运行开发工具并保存项目文件；Bibimer 通过移动界面集中管理项目、智能体会话、聊天和终端。

在 Google Play 获取 Bibimer

目前 Google Play 上的应用支持英语和韩语，更多应用语言正在准备中。本指南保留英文按钮名称，方便你在已发布的应用中找到对应功能。

01安装并打开 Termux

请从 Termux 官方安装指南列出的来源安装。安装后打开一次，等待初始设置完成。

Termux 及其插件应从同一来源安装。按照本指南操作，无需另备开发电脑。

02将 Bibimer 连接到 Termux

在 Bibimer 中打开 Setup → Manual setup and pairing → Save setup file。将文件以 bibimer-setup.sh 的名称保存到 Android 的 Download 文件夹。

在 Termux 中运行以下命令，并授予文件访问权限。如果已能访问 Download 文件夹，可跳过此命令。

termux-setup-storage

然后运行：

bash ~/storage/downloads/bibimer-setup.sh

脚本会按需安装 Python，安装本地 Bibimer 桥接程序并启动它。将 Termux 中显示的8 位一次性配对码输入 Bibimer 的 Connect this app 区域。配对码五分钟内有效。

如果使用了其他文件名或保存位置，请相应调整命令中的路径。

03打开项目并试用终端

打开侧边栏，选择 Project Add。浏览 Termux 中的文件夹，或输入 ~/projects/my-project 等路径；如有需要，选择创建文件夹，然后保存项目。

选择 Terminal 并启动会话。输入以下命令并发送：

pwd

输出会显示手机上当前项目文件夹的路径。完成这一步无需 AI 提供商账户。

04按需添加编程智能体

在 Termux 中准备兼容的 Codex、Claude Code 或 OpenCode 安装，并完成所需的提供商登录或 API 配置。然后在 Bibimer 中选择智能体并启动会话。

可用模型和选项取决于安装的智能体。通用 Linux 安装指南并不保证适用于 Android/Termux。提供商的费用和数据政策另行适用。

05管理你的工作

通过侧边栏切换项目、已有的 Git 工作树和会话。Chat 显示受支持智能体的结构化回复和审批请求；Terminal 提供命令行界面。打开文件浏览器，可查看项目文件、Git 状态和更改。

切换页面或关闭 Bibimer 不会请求停止会话。Android 可能会停止后台进程；重启桥接程序不会恢复已丢失的进程或终端输出。归档会话后，其任务仍会继续运行。请在 Termux 中创建或删除 Git 工作树。

在 Settings → Language 中选择应用显示语言。输入内容、项目名称和终端输出不会被翻译。

需要帮助？

如果连接失败，请先确认 Termux 和桥接程序仍在运行。寻求帮助时，请说明进行到哪一步，并提供错误提示。请勿发送密码、API 密钥或私有项目文件。
