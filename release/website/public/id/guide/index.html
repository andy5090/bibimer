Proyek pertama Anda, di ponsel

Mulai menggunakan Bibimer

Pasang Bibimer dan Termux di ponsel Android yang sama. Termux menjalankan alat pengembangan dan menyimpan berkas proyek; Bibimer menyatukan proyek, sesi agen, percakapan, dan terminal dalam antarmuka seluler.

Dapatkan Bibimer di Google Play

Aplikasi dan situs mendukung sepuluh bahasa. Aplikasi mengikuti bahasa perangkat secara default; pilih bahasa lain di Pengaturan.

01Pasang dan buka Termux

Pasang Termux dari salah satu sumber yang tercantum dalam panduan pemasangan resminya. Buka sekali dan tunggu hingga penyiapan awal selesai.

Pasang Termux dan pengayanya dari sumber distribusi yang sama. Anda tidak memerlukan komputer pengembangan terpisah untuk mengikuti panduan ini.

02Hubungkan Bibimer dengan Termux

Di Bibimer, buka Setup → Manual setup and pairing → Save setup file. Simpan berkas dengan nama bibimer-setup.sh di folder Download Android.

Di Termux, jalankan perintah berikut dan berikan izin akses berkas. Lewati langkah ini jika folder Download sudah dapat diakses.

termux-setup-storage

Lalu jalankan:

bash ~/storage/downloads/bibimer-setup.sh

Skrip menyiapkan Python jika diperlukan, memasang penghubung lokal Bibimer, lalu menjalankannya. Masukkan kode sekali pakai 8 digit yang ditampilkan di Termux ke bagian Connect this app di Bibimer. Kode berlaku selama lima menit.

Jika berkas disimpan dengan nama atau folder lain, sesuaikan jalur dalam perintah.

03Buka proyek dan coba terminal

Buka bilah samping dan pilih Project Add. Telusuri folder di Termux atau masukkan jalur seperti ~/projects/my-project, lalu pilih untuk membuat folder jika diperlukan. Simpan proyek.

Pilih Terminal dan mulai sesi. Ketik lalu kirim perintah ini:

pwd

Keluaran menampilkan folder proyek saat ini di ponsel. Pemeriksaan awal ini tidak memerlukan akun penyedia AI.

04Tambahkan agen pemrograman saat diperlukan

Siapkan instalasi Codex, Claude Code, atau OpenCode yang kompatibel di Termux, termasuk login penyedia atau konfigurasi API yang dibutuhkan. Lalu pilih agen di Bibimer dan mulai sesi.

Model dan opsi yang tersedia bergantung pada agen yang dipasang. Petunjuk pemasangan Linux secara umum tidak menjamin kompatibilitas dengan Android/Termux. Biaya dan kebijakan data penyedia berlaku secara terpisah.

Panduan instalasi agen di Termux (bahasa Inggris)

05Kelola pekerjaan Anda

Gunakan bilah samping untuk berpindah antara proyek, worktree Git yang sudah ada, dan sesi. Chat menampilkan respons terstruktur dan permintaan persetujuan dari agen yang didukung; Terminal menyediakan antarmuka baris perintah. Buka penjelajah berkas untuk memeriksa berkas proyek, status Git, dan perubahan.

Berpindah layar atau menutup Bibimer tidak meminta sesi berhenti. Android dapat menghentikan proses latar belakang; memulai ulang penghubung tidak memulihkan proses atau keluaran terminal yang hilang. Mengarsipkan sesi tetap membiarkan pekerjaannya berjalan.

Gunakan Settings → Language untuk memilih bahasa tampilan aplikasi. Masukan Anda, nama proyek, dan keluaran terminal tidak diterjemahkan.

Sesi, input, dan pemeliharaan bridge

Buat worktree Git dan mulai sesi dari bilah samping. Gunakan Steer saat Codex atau Claude merespons, kirim pesan antrean secara berkelompok, dan gunakan Ctrl+Enter untuk mengirim jika Enter membuat baris baru.

Settings menampilkan sesi aktif dari semua proyek, worktree, arsip, dan terminal sebelum pembaruan atau mulai ulang bridge. Konfirmasi untuk mengakhiri sesi yang tercantum; pemeliharaan dimulai setelah penghentian terverifikasi. Respons berjalan dan antrean dapat hilang; keluaran PTY tidak dipulihkan. Batalkan untuk mempertahankan sesi. Perbarui bridge di Settings saat aplikasi meminta. Hapus worktree melalui Git di Termux. Shift+Enter selalu membuat baris baru; Ctrl+Enter membuat baris baru jika Enter diatur untuk mengirim.

Butuh bantuan?

Jika koneksi gagal, periksa apakah Termux dan penghubung masih berjalan. Saat meminta bantuan, sebutkan langkah terakhir yang Anda lakukan dan pesan kesalahannya. Jangan kirim kata sandi, kunci API, atau berkas proyek pribadi.
