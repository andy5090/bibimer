Seu primeiro projeto, no celular

Primeiros passos com o Bibimer

Você precisa do Bibimer e do Termux no mesmo celular Android. O Termux executa as ferramentas de desenvolvimento e guarda os arquivos; o Bibimer reúne projetos, sessões de agentes, conversas e terminais em uma interface móvel.

Baixar o Bibimer no Google Play

O app disponível no Google Play oferece inglês e coreano. Mais idiomas estão em preparação. Este guia mantém os nomes dos botões em inglês para facilitar sua localização na versão publicada.

01Instale e abra o Termux

Instale o Termux por uma das fontes indicadas no guia oficial de instalação. Abra-o uma vez e aguarde a conclusão da configuração inicial.

Instale o Termux e seus complementos pela mesma fonte. Você não precisa de um computador de desenvolvimento separado para seguir este guia.

02Conecte o Bibimer ao Termux

No Bibimer, abra Setup → Manual setup and pairing → Save setup file. Salve o arquivo como bibimer-setup.sh na pasta Downloads do Android.

No Termux, execute o comando abaixo e conceda a permissão de acesso aos arquivos. Pule esta etapa se a pasta Downloads já estiver acessível.

termux-setup-storage

Depois, execute:

bash ~/storage/downloads/bibimer-setup.sh

O script prepara o Python, se necessário, instala a ponte local do Bibimer e a inicia. Digite o código de uso único de 8 dígitos exibido no Termux na seção Connect this app do Bibimer. O código vale por cinco minutos.

Se você salvou o arquivo com outro nome ou em outra pasta, ajuste o caminho no comando.

03Abra um projeto e teste o terminal

Abra a barra lateral e escolha Project Add. Procure uma pasta no Termux ou digite um caminho como ~/projects/my-project e escolha criar a pasta, se necessário. Salve o projeto.

Selecione Terminal e inicie uma sessão. Digite e envie este comando:

pwd

A saída mostra a pasta atual do projeto no celular. Essa primeira verificação não exige uma conta de provedor de IA.

04Adicione um agente de programação quando precisar

Prepare uma instalação compatível do Codex, Claude Code ou OpenCode no Termux, incluindo o login no provedor ou a configuração de API necessária. Depois, escolha o agente no Bibimer e inicie uma sessão.

Os modelos e as opções disponíveis dependem do agente instalado. Instruções gerais de instalação no Linux não garantem compatibilidade com Android/Termux. As tarifas e políticas de dados do provedor se aplicam separadamente.

05Organize seu trabalho

Use a barra lateral para alternar entre projetos, worktrees existentes do Git e sessões. O Chat mostra respostas estruturadas e solicitações de aprovação dos agentes compatíveis; o Terminal oferece a interface de linha de comando. Abra o explorador de arquivos para consultar os arquivos do projeto, o status do Git e as alterações.

Trocar de tela ou fechar o Bibimer não solicita o encerramento das sessões. O Android pode interromper processos em segundo plano; reiniciar a ponte não restaura processos perdidos nem a saída do terminal. Arquivar uma sessão mantém o trabalho em execução. Crie ou remova worktrees do Git no Termux.

Use Settings → Language para escolher o idioma do app. Suas entradas, os nomes dos projetos e a saída do terminal não são traduzidos.

Precisa de ajuda?

Se a conexão falhar, verifique se o Termux e a ponte continuam em execução. Ao pedir ajuda, informe a etapa em que parou e a mensagem de erro. Não envie senhas, chaves de API nem arquivos privados do projeto.
