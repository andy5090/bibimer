휴대폰에서 시작하는 첫 프로젝트

Bibimer 시작하기

같은 안드로이드 휴대폰에 Bibimer와 Termux를 설치하세요. Termux가 개발 도구를 실행하고 프로젝트 파일을 보관하며, Bibimer는 프로젝트·에이전트 세션·대화·터미널을 모바일 화면에서 관리할 수 있게 해줍니다.

Google Play에서 Bibimer 설치

현재 Google Play 앱은 영어와 한국어를 지원합니다. 다른 앱 언어는 준비 중입니다. 이 안내에서는 출시된 앱에서 쉽게 찾을 수 있도록 영어 버튼 이름을 함께 사용합니다.

01Termux 설치하고 열기

Termux 공식 설치 안내에 나온 배포처에서 설치하세요. 설치 후 한 번 열어 초기 설정이 끝날 때까지 기다립니다.

Termux와 부가 앱은 같은 배포처에서 설치하세요. 이 안내를 따라가는 데 별도의 개발용 컴퓨터는 필요하지 않습니다.

02Bibimer와 Termux 연결하기

Bibimer에서 Setup → Manual setup and pairing → Save setup file을 선택하세요. 파일 이름은 bibimer-setup.sh로 하고 Android의 Download 폴더에 저장합니다.

Termux에서 아래 명령을 실행하고 파일 접근 권한을 허용하세요. 이미 Download 폴더에 접근할 수 있다면 건너뛰어도 됩니다.

termux-setup-storage

이어서 다음 명령을 실행하세요.

bash ~/storage/downloads/bibimer-setup.sh

설치 파일이 필요에 따라 Python을 준비하고, 로컬 Bibimer 브리지를 설치한 뒤 실행합니다. Termux에 표시된 8자리 일회용 코드를 Bibimer의 Connect this app 항목에 입력하세요. 코드는 5분 동안 유효합니다.

파일 이름이나 저장 폴더를 바꿨다면 명령의 경로도 그에 맞게 바꿔 주세요.

03프로젝트 열고 터미널 사용하기

사이드바에서 Project Add를 선택하세요. Termux의 폴더를 찾거나 ~/projects/my-project 같은 경로를 입력합니다. 폴더가 없으면 새로 만들기를 선택하고 프로젝트를 저장하세요.

Terminal을 선택해 세션을 시작한 뒤, 아래 명령을 입력하고 보내세요.

pwd

휴대폰에 있는 현재 프로젝트 폴더의 경로가 출력됩니다. 여기까지는 AI 제공자 계정 없이 확인할 수 있습니다.

04필요한 코딩 에이전트 연결하기

Termux에서 실행할 수 있는 Codex·Claude Code·OpenCode를 설치하고 해당 제공자의 로그인이나 API 설정을 마치세요. Bibimer에서 에이전트를 선택하고 세션을 시작합니다.

사용할 수 있는 모델과 옵션은 설치한 에이전트에 따라 다릅니다. 일반 Linux 설치 안내가 Android/Termux에서도 그대로 동작한다는 뜻은 아닙니다. 제공자의 요금과 데이터 정책은 별도로 적용됩니다.

05프로젝트와 세션 관리하기

사이드바에서 프로젝트·기존 Git 워크트리·세션을 전환하세요. Chat에서는 지원하는 에이전트의 응답과 승인 요청을 읽고 처리하며, Terminal에서는 CLI 화면을 사용합니다. 파일 탐색기를 열면 프로젝트 파일과 Git 상태·변경 내용을 확인할 수 있습니다.

화면을 바꾸거나 Bibimer를 닫아도 세션 종료를 요청하지 않습니다. 다만 Android가 백그라운드 프로세스를 중지할 수 있고, 브리지를 다시 시작해도 유실된 프로세스나 터미널 출력은 복구되지 않습니다. 세션을 보관해도 작업은 계속됩니다. Git 워크트리 생성·삭제는 Termux에서 진행하세요.

Settings → Language에서 앱 표시 언어를 선택할 수 있습니다. 직접 입력한 내용과 프로젝트 이름, 터미널 출력은 번역하지 않습니다.

도움이 필요하신가요?

연결이 안 되면 Termux와 브리지가 실행 중인지 먼저 확인하세요. 문의할 때는 어느 단계까지 진행했는지와 오류 메시지를 알려 주세요. 비밀번호·API 키·비공개 프로젝트 파일은 보내지 마세요.
