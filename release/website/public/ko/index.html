휴대폰에서 이어가는 프로젝트

프로젝트 파일과 Git, 호환되는 개발 도구를 휴대폰의 Termux에서 실행합니다. 별도의 개발 컴퓨터나 원격 호스트 없이 프로젝트와 기존 워크트리를 관리하세요.

대화와 터미널

구조화된 대화와 도구 실행을 확인하세요. 지시를 보내고, 승인 요청에 응답하고, 후속 입력을 대기열에 추가할 수 있습니다.

직접 선택하는 에이전트

호환되는 Codex·Claude·OpenCode 설치본을 연결하세요. 설치한 에이전트가 지원하는 모델과 옵션을 선택할 수 있습니다.

파일과 Git 변경 사항 확인

코드의 구문을 강조해 읽고 Git 변경 사항을 확인하세요. Markdown·정적 HTML·Mermaid 다이어그램을 미리 볼 수 있습니다. Office 문서·이미지·PDF는 호환되는 Android 앱으로 엽니다.

0.25.0 업데이트

현재 공개 버전은 0.23.0입니다. 0.25.0은 초대된 내부 테스터에게 제공되며 정식 배포 심사에 제출했습니다.

사이드바에서 Git 워크트리를 만들고 세션을 시작할 수 있습니다. Codex·Claude 응답 중 Steer로 추가 지시를 전달하고, 대기 메시지를 묶어서 보내며, Enter가 줄바꿈일 때 Ctrl+Enter로 전송합니다. 첫 화면 초기화 오류 수정도 포함했습니다.

0.25.0의 설정에서는 브리지 업데이트·재시작 전 모든 프로젝트·워크트리·보관함·터미널의 실행 세션을 보여줍니다. 확인한 세션의 실제 종료가 검증된 뒤 유지보수를 시작합니다. 진행 중 응답과 대기 입력이 사라질 수 있고 PTY 출력은 복원되지 않습니다. 취소하면 세션을 유지합니다. 워크트리 생성·Claude Steer에는 브리지 0.18.0이 필요하므로 설정에서 업데이트하세요. 워크트리 삭제는 Termux의 Git에서 진행합니다. Shift+Enter는 항상 줄바꿈이며, Enter가 보내기이면 Ctrl+Enter는 줄바꿈합니다.

Termux로 시작하세요

Termux는 Android에서 Linux 명령줄 환경을 제공하는 앱입니다. Git, Python, Node.js 등 다양한 도구를 쓸 수 있습니다. 같은 휴대폰에 설치하고 Bibimer의 설정 안내에 따라 터미널부터 사용해 보세요. 호환되는 에이전트 설치와 제공자 인증은 별도 단계입니다.

에이전트는 입력·코드·파일을 설정된 제공자나 도구에 전송할 수 있습니다. 이용 요금과 연령 요건은 사용하는 서비스에 따라 달라집니다.

왜 비비머인가요?

Android 앱, Termux, 코딩 에이전트를 하나로 비볐습니다. 세 가지를 함께 쓰는 개발 환경이라는 뜻을 담아, ‘비빔’에 ‘-er’를 붙여 Bibimer(비비머)라는 이름을 지었습니다.
