1. 처리 목적과 정보

Bibimer는 같은 Android 휴대폰의 Termux에서 프로젝트와 코딩 에이전트 세션을 관리하는 모바일 에이전트 개발 환경(ADE)입니다. 프로젝트 이름·폴더 경로, 세션 식별자·설정, 입력·답변, 터미널·도구 출력, 사용자가 작업 대상으로 선택한 파일을 처리합니다. 프로젝트·세션 표시, 지시 전달, 결과 확인 및 사용자가 요청한 기능 제공을 위해 사용합니다.

Android 화면은 같은 기기의 인증된 브리지와 통신합니다. 앱은 설정과 연결 정보를 앱 전용 저장소에 보관하며 연결 토큰은 Android Keystore로 암호화합니다. 프로젝트·세션 메타데이터와 에이전트 기록은 Termux에서 별도로 보관합니다. 현재 Android 앱에는 광고·분석 SDK와 대화를 Bibimer 운영 서버로 업로드하는 기능이 없습니다.

심사용 데모는 비공개 코드를 기기에서 확인한 뒤 열 수 있으며 입력한 코드 원문을 보관하지 않습니다. 데모 모드는 메모리에 있는 가상의 예제 로그를 재생합니다. 대화·터미널 입력은 준비된 응답에 영향을 주지 않으며 예제 기록에 남기지 않습니다. 데모 재생 중에는 에이전트나 명령을 실행하거나 사용자 프로젝트 파일에 접근하거나 제공자에 요청을 보내지 않습니다. 데모 설정은 따로 저장하며 데모에서 나가면 예제 공간을 초기화하고 기존 설정으로 돌아갑니다. 개인정보처리방침을 선택하면 브라우저가 열릴 수 있습니다.

2. 코딩 에이전트와 외부 서비스

지시를 전송하면 선택한 에이전트가 입력·코드·파일·대화 맥락·도구 요청을 설정된 AI 제공자나 다른 서비스로 전송할 수 있습니다. 처리와 보관은 사용하는 에이전트·제공자·계정·권한·설정에 따라 달라집니다. 로컬 브리지 연결이 모든 AI 처리를 기기 안에서 수행한다는 뜻은 아닙니다.

다른 에이전트로 대화를 이어갈 때는 사용자가 확인하고 전송한 맥락을 대상 에이전트에 전달하며 해당 기록에 남을 수 있습니다. 도구 설치나 외부 링크 열기 때 Termux·패키지 저장소·개발 도구·외부 웹사이트도 요청을 처리합니다. 선택한 서비스의 방침을 확인하세요.

3. GitHub 연결과 파일 열기

GitHub 가져오기는 Termux의 GitHub CLI로 인증하고 접근 가능한 저장소를 조회한 뒤 선택한 저장소를 클론합니다. 자격 증명은 Termux의 GitHub CLI가 관리합니다. Bibimer는 계정 상태·저장소 정보와 필요한 일시적 로그인 코드를 표시하며 인증 토큰을 WebView나 일반 로그에 전달하지 않습니다. 클론한 파일은 사용자가 선택한 폴더에 남습니다.

프로젝트나 Download의 파일을 다른 Android 앱으로 열면 앱 전용 캐시에 임시 복사본을 만들고 선택한 뷰어에 임시 읽기 권한을 부여합니다. 뷰어는 자신의 처리 방침에 따라 파일을 사용합니다. 복사본을 수정해도 원본 프로젝트 파일은 바뀌지 않습니다. 캐시 복사본에는 용량·만료 제한이 있으며 이후 앱 사용이나 연결 해제 때 정리됩니다.

4. 알림과 권한

알림 권한과 응답 감시를 켜면 완료 알림에 프로젝트·세션 이름과 완료 답변 앞부분 최대 180자가 포함될 수 있습니다. 공개 잠금 화면 버전에는 일반 완료 문구를 사용합니다. Android 알림 설정과 알림 접근 권한을 가진 다른 앱에 따라 내용에 접근할 수 있습니다. Settings나 지속 알림에서 감시를 중지할 수 있습니다.

Termux 명령 접근에는 Android 권한과 Termux 외부 앱 연동 설정이 필요합니다. Bibimer는 사용자가 요청한 설치·개발 작업을 전달하는 데 사용합니다. 완료 미리보기는 브리지 메타데이터 파일이나 일반 로그에 저장하지 않습니다.

5. 보관·삭제·사용자 제어

앱 설정과 연결 정보는 앱 데이터 삭제나 앱 제거 때까지 보관합니다. 최근 브리지 출력과 대기 입력은 실행 중인 세션의 제한된 메모리에 유지하며 프로세스 종료나 브리지 재시작 때 사라질 수 있습니다. Termux의 프로젝트 파일·세션 메타데이터·원본 에이전트 기록은 별도로 저장하며 보관 기간은 사용자의 조작과 에이전트 설정에 따릅니다.

프로젝트 등록 해제나 종료된 세션의 목록 삭제는 Bibimer의 등록 정보만 제거합니다. 프로젝트 폴더·Git 워크트리·원본 에이전트 기록을 지우지 않습니다. 실제 파일과 기록은 Termux와 해당 에이전트에서 별도로 삭제하세요. Bibimer를 제거해도 삭제되지 않습니다. 제공자에 보관된 정보는 해당 제공자에 삭제를 요청하세요.

Bibimer 자체 사용자 계정은 만들지 않습니다. GitHub·AI 제공자 계정은 각 서비스가 관리합니다. 앱에서 로컬 브리지 연결을 해제하고 관련 서비스나 도구에서 외부 서비스 접근을 철회할 수 있습니다.

데이터 삭제 요청과 삭제 방법 안내

  1. 제목을 Bibimer 데이터 삭제로 적어 andy@andineering.com으로 보내 주세요.
  2. 앱 설정, Termux 파일, 에이전트·제공자 기록, 이전 문의 메일 중 어떤 데이터를 삭제하려는지 알려 주세요. 비밀번호·API 키·비공개 프로젝트 파일은 보내지 마세요.
  3. 앤디니어링이 보관하는 문의 메일 등은 직접 처리하고, 기기에 저장된 데이터는 삭제 방법을 안내합니다. 앤디니어링은 Termux 프로젝트 파일이나 에이전트 기록의 사본을 보관하지 않습니다. 해당 파일은 기기에서 직접 삭제하고, 제공자가 보관하는 데이터는 해당 제공자에 삭제를 요청해 주세요.

기기 데이터는 위 방법으로 삭제할 때까지 남습니다. 외부 제공자의 기록은 각 제공자의 보관 정책을 따릅니다. 문의 메일은 요청을 처리하거나 법적 의무를 이행하는 데 필요한 기간만 보관하며, 같은 이메일로 삭제를 요청할 수 있습니다.

6. 대상 연령

Bibimer는 13세 이상 사용자를 대상으로 합니다. 외부 에이전트·제공자·개발 서비스에는 별도의 연령·계정 요건이 있으며 더 높은 연령을 요구할 수 있습니다.

7. 웹사이트 호스팅

이 웹사이트는 Cloudflare Pages에서 제공합니다. Cloudflare는 웹사이트 전송과 보호를 위해 IP 주소·트래픽 정보 등 접속 요청 정보를 처리하며 해외 인프라에서 처리할 수 있습니다. 자세한 내용은 Cloudflare 개인정보처리방침에서 확인할 수 있습니다. 이 정적 사이트에는 앤디니어링이 추가한 계정·문의 폼·광고·분석 스크립트가 없습니다.

8. 문의와 변경

개인정보 문의와 열람·정정·삭제 요청은 위 연락처로 받습니다. 문의에 답변하고 처리하기 위해 발신 이메일·문의 내용·첨부파일을 처리합니다. 문의에 필요한 정보만 보내 주세요. 처리 방식이 달라지면 방침 내용과 시행일을 갱신합니다.
