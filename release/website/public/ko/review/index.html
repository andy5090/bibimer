가상 예제로 실제 Android 기능을 확인하세요

이 안내는 비공개 접근 코드를 받은 앱 심사자용입니다. 코드 인증 후에는 계정이나 Termux 없이 예제 화면을 둘러볼 수 있습니다. 데모는 실제 기록을 사용하지 않은 가상의 세션 로그를 재생합니다. 입력에 답하거나 명령을 실행하거나 AI 제공자에 요청을 보내지 않습니다.

  1. Bibimer에서 설정 → 심사자용 접근을 열고 Play Console의 비밀번호 항목에 제공한 비공개 코드를 입력하세요. 코드는 다시 사용할 수 있으며 이 페이지에 공개하지 않습니다. 인증 후에도 데모 안내는 계속 표시됩니다.
  2. 프로젝트 사이드바에서 예제 Codex·Claude Code·OpenCode·터미널 세션을 선택하세요. 코드·표·diff·계획·도구 카드 등 서로 다른 가상 예제를 확인할 수 있습니다.
  3. 아무 내용이나 보내면 다음 예제를 재생합니다. 응답은 미리 준비되어 있으며 입력과 관계없습니다. 첫 두 예제는 자동으로 끝나고 세 번째마다 승인 카드와 질문이 나옵니다. 예제 승인을 눌러도 명령은 실행하지 않습니다.
  4. 예제 프로젝트·워크트리·세션 관리·모델·대기열·파일 미리보기·Git 변경·기록·가상의 GitHub 가져오기를 둘러보세요. 예제 작업은 격리된 데모 안에서만 처리합니다.
  5. 알림을 체험하려면 설정에서 응답 완료 알림을 켜고 Android 알림 권한을 허용하세요. 자동으로 끝나는 예제를 시작한 뒤 Android 홈으로 이동하고 알림 창을 여세요. 지속 알림과 완료 알림에는 데모라고 표시됩니다. 완료 알림을 누르면 해당 예제 세션을 열며 지속 알림이나 설정에서 감시를 끌 수 있습니다.
  6. 데모 나가기를 누르면 실제 Termux 준비 화면으로 돌아갑니다. 실제 에이전트 작업에는 Termux와 별도로 준비한 제공자 도구가 필요합니다. 데모가 외부 연동의 실제 검증을 대신하지는 않습니다.

아래 알림 영상은 0.16.0에서 촬영했습니다. 0.16.1에 추가한 비공개 코드 입력 과정은 영상에 포함되어 있지 않습니다.

완료 알림 시연

이 영상은 가상의 완료 이벤트로 실제 Android 포그라운드 서비스·알림 제어·세션 이동을 보여줍니다. 예제 알림의 동작을 확인하는 영상이며 실제 코딩 에이전트 응답이나 제공자 연동 검증 영상은 아닙니다.
