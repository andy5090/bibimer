Tu primer proyecto, en tu teléfono

Primeros pasos con Bibimer

Necesitas Bibimer y Termux en el mismo teléfono Android. Termux ejecuta las herramientas de desarrollo y guarda los archivos; Bibimer reúne proyectos, sesiones de agentes, chats y terminales en una interfaz móvil.

Obtener Bibimer en Google Play

La app actual de Google Play está disponible en inglés y coreano. Se están preparando más idiomas para la app. Esta guía conserva los nombres de los botones en inglés para que puedas encontrarlos en la versión publicada.

01Instala y abre Termux

Instala Termux desde una de las fuentes indicadas en su guía oficial de instalación. Ábrelo una vez y espera a que termine la configuración inicial.

Instala Termux y sus complementos desde la misma fuente. No necesitas un ordenador de desarrollo aparte para seguir esta guía.

02Conecta Bibimer con Termux

En Bibimer, abre Setup → Manual setup and pairing → Save setup file. Guarda el archivo como bibimer-setup.sh en la carpeta de descargas de Android.

En Termux, ejecuta este comando y concede el permiso de acceso a archivos. Omítelo si ya puedes acceder a la carpeta de descargas.

termux-setup-storage

Después ejecuta:

bash ~/storage/downloads/bibimer-setup.sh

El script prepara Python si hace falta, instala el puente local de Bibimer y lo inicia. Introduce el código de un solo uso de 8 dígitos que aparece en Termux en la sección Connect this app de Bibimer. El código es válido durante cinco minutos.

Si guardaste el archivo con otro nombre o en otra carpeta, ajusta la ruta del comando.

03Abre un proyecto y prueba el terminal

Abre la barra lateral y elige Project Add. Busca una carpeta de Termux o escribe una ruta como ~/projects/my-project y elige crearla si hace falta. Guarda el proyecto.

Selecciona Terminal e inicia una sesión. Escribe y envía este comando:

pwd

La salida muestra la carpeta actual del proyecto en tu teléfono. Esta primera comprobación no requiere una cuenta de un proveedor de IA.

04Añade un agente de programación cuando lo necesites

Prepara una instalación compatible de Codex, Claude Code u OpenCode en Termux, incluido el inicio de sesión o la configuración de API que requiera su proveedor. Después elige el agente en Bibimer e inicia una sesión.

Los modelos y las opciones dependen del agente instalado. Las instrucciones generales para Linux no garantizan compatibilidad con Android/Termux. Las tarifas y políticas de datos del proveedor se aplican por separado.

05Organiza tu trabajo

Usa la barra lateral para cambiar entre proyectos, worktrees de Git existentes y sesiones. Chat muestra las respuestas estructuradas y las solicitudes de aprobación de los agentes compatibles; Terminal ofrece su interfaz de línea de comandos. Abre el explorador de archivos para revisar los archivos del proyecto, el estado de Git y los cambios.

Cambiar de pantalla o cerrar Bibimer no solicita detener las sesiones. Android puede detener procesos en segundo plano; reiniciar el puente no recupera procesos perdidos ni su salida de terminal. Archivar una sesión mantiene su trabajo en ejecución. Crea o elimina worktrees de Git en Termux.

Usa Settings → Language para elegir el idioma de la app. Tu entrada, los nombres de los proyectos y la salida del terminal no se traducen.

¿Necesitas ayuda?

Si falla la conexión, comprueba que Termux y el puente sigan en ejecución. Al pedir ayuda, indica el paso al que llegaste y el mensaje de error. No envíes contraseñas, claves API ni archivos privados del proyecto.
