Your first project, on your phone

Get started with Bibimer

You need Bibimer and Termux on the same Android phone. Termux runs your development tools and keeps your project files; Bibimer brings projects, agent sessions, chat, and terminals together in a mobile interface.

Get Bibimer on Google Play

The app and website support ten languages. The app follows your device language by default; you can choose another in Settings.

01Install and open Termux

Install Termux from a source listed in its official installation guide. Open it once and let the initial setup finish.

Install Termux and any add-ons from the same distribution source. You do not need a separate development computer to follow this guide.

02Connect Bibimer to Termux

In Bibimer, open Setup → Manual setup and pairing → Save setup file. Save the file as bibimer-setup.sh in Android’s Downloads folder.

In Termux, run the following command and grant the requested file access. Skip it if the Downloads folder is already accessible.

termux-setup-storage

Then run:

bash ~/storage/downloads/bibimer-setup.sh

The script prepares Python if needed, installs the local Bibimer bridge, and starts it. Enter the 8-digit one-time code shown in Termux into Bibimer’s Connect this app section. The code is valid for five minutes.

If you saved the file under another name or in another folder, adjust the path in the command.

03Open a project and try the terminal

Open the sidebar and choose Project Add. Browse to a folder in Termux, or enter a path such as ~/projects/my-project and choose to create the folder if needed. Save the project.

Select Terminal and start a session. Enter this command and send it:

pwd

The output shows your project’s current folder on the phone. This first check does not require an AI provider account.

04Add a coding agent when you need one

Prepare a compatible Codex, Claude Code, or OpenCode installation in Termux, including the provider login or API configuration it requires. Then choose the agent in Bibimer and start a session.

Available models and options depend on the installed agent. General Linux installation instructions do not guarantee Android/Termux compatibility. Provider fees and data policies apply separately.

Termux agent installation guide (English)

05Keep your work organized

Use the sidebar to switch between projects, existing Git worktrees, and sessions. Chat shows supported agents’ structured responses and approval requests; Terminal provides their command-line interface. Open the file browser to inspect project files, Git status, and changes.

Switching screens or closing Bibimer does not request that sessions stop. Android may stop background processes; restarting the bridge does not restore lost processes or terminal output. Archiving keeps a session’s work running.

Use Settings → Language to choose the app’s display language. Your input, project names, and terminal output stay unchanged.

New in 0.25.0

Public release: 0.23.0. Version 0.25.0 is available to invited internal testers and has been submitted for production review.

Create a Git worktree and start a session from the sidebar. Steer an active Codex or Claude response, send queued follow-ups together, and use Ctrl+Enter to send when Enter inserts a newline. Version 0.25.0 also includes the first-screen startup fix.

With 0.25.0, Settings shows running sessions across projects, worktrees, the archive, and terminals before a bridge update or restart. Confirm to end the listed sessions; maintenance starts only after their termination is verified. Ongoing responses and queued input can be lost, and PTY output is not restored. Cancel to keep sessions running. New worktree and Claude Steer features require bridge 0.18.0; update it in Settings. Worktree deletion stays in Git in Termux. Shift+Enter always inserts a newline; Ctrl+Enter inserts a newline when Enter is set to send.

Need a hand?

If the connection fails, check that Termux and the bridge are still running. Share the step you reached and the error message when asking for help. Do not send passwords, API keys, or private project files.
