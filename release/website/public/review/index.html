Fictional examples, real Android controls

This resource is for authorized app reviewers with a private access code. No account or Termux is needed after access is granted. Demo replays fictional session logs; it does not use real transcripts, respond to your input, run commands, or contact an AI provider.

  1. Open Bibimer and go to Settings → Review access. Enter the private code supplied in Play Console’s password field. The code is reusable; it is not published on this page. The Demo banner stays visible after access is granted.
  2. Open the project sidebar and choose the sample Codex, Claude Code, OpenCode, or Terminal session. The sessions show different fictional examples with code, tables, diffs, plans, and tool cards.
  3. Send any text to replay the next sample. Responses are prerecorded and unrelated to the text you submit. The first two examples finish automatically; every third example offers an approval card followed by a question. Accepting a sample approval does not execute a command.
  4. Explore sample projects, worktrees, session management, models, queue controls, file previews, Git changes, history, and the fictional GitHub import. All sample operations stay inside the isolated demo.
  5. In Settings, enable response notifications and allow Android notification permission if you want to try alerts. Start an automatic example, return to the Android home screen, and open the notification shade. The ongoing monitor and completion alert are labeled Demo. Tap the completion alert to open its sample session. Stop monitoring from the ongoing notification or Settings.
  6. Choose Exit demo to return to normal Termux setup. Real agent work requires Termux and separately configured provider tools. Demo does not verify those external integrations.
