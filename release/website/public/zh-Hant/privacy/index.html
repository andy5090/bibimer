1. 用途與處理的資訊

Bibimer 是一款行動代理開發環境（ADE），用於管理同一部 Android 手機上 Termux 中的專案和程式開發代理工作階段。它會處理專案名稱和資料夾路徑、工作階段識別碼與設定、指令、回覆、終端機和工具輸出，以及你選擇使用的檔案。這些資訊用於顯示專案和工作階段、傳送指令、展示結果，以及提供你請求的功能。

Android 介面與同一裝置上經過身分驗證的橋接服務通訊。應用程式將偏好設定和連線資訊儲存在其私有儲存空間中，並使用 Android Keystore 加密連線權杖。Termux 單獨儲存專案和工作階段中繼資料以及 AI 代理紀錄。目前 Android 應用程式不含廣告或分析 SDK，也沒有將對話上傳至 Bibimer 營運伺服器的功能。

審核示範需要使用私密存取碼，存取碼在本機驗證，提交後不會保留。示範模式從記憶體中重播虛構的範例工作階段紀錄。聊天和終端機輸入不會影響預設回覆，也不會儲存在範例紀錄中。示範重播不會執行 AI 代理或指令，不會存取你的專案檔案，也不會聯絡服務供應商。示範偏好設定單獨儲存；退出示範時會重置範例工作區，並恢復你的正常設定。如果你選擇開啟本隱私政策，應用程式可能會啟動瀏覽器。

2. 程式開發代理與外部服務

傳送指令時，你選擇的 AI 代理可能會將提示詞、程式碼、檔案、對話上下文和工具請求傳輸給其設定的 AI 服務供應商及其他服務。處理與保留方式取決於你使用的 AI 代理、服務供應商、帳號、權限和設定。連線本機橋接服務並不意味著 AI 處理僅在裝置上進行。

如果你選擇透過另一 AI 代理繼續對話，你查看並傳送的上下文會傳遞給該 AI 代理，並可能儲存在其紀錄中。安裝工具或開啟連結時，Termux、套件庫、開發工具和外部網站也會處理相關請求。請查閱你所選擇服務的政策。

3. GitHub 與檔案開啟

GitHub 匯入功能使用 Termux 中的 GitHub CLI 進行身分驗證、列出你有權存取的儲存庫，並複製你選擇的儲存庫。GitHub CLI 在 Termux 中管理其憑證。Bibimer 顯示帳號狀態、儲存庫資訊，以及在需要時顯示暫時登入碼；不會將身分驗證權杖傳送到 WebView 或一般紀錄。複製的檔案儲存在你選擇的資料夾中。

當你選擇在其他 Android 應用程式中開啟專案檔案或下載檔案時，Bibimer 會在其私有快取中建立暫時副本，並授予所選檢視器暫時讀取權限。檢視器隨後會按其自身慣例處理該檔案。編輯此副本不會更改原始專案檔案。快取副本有大小和有效期限制，會在後續使用應用程式或斷開連線時清理。

4. 通知與權限

授予通知權限並開啟回覆監控後，完成通知可能包含專案和工作階段名稱，以及已完成回覆中的最多 180 個字元。鎖定畫面公開版本使用通用的完成提示。Android 通知設定及其他擁有通知讀取權限的應用程式可能影響誰能看到通知內容。你可以在設定中或透過常駐通知停止監控。

Termux 指令存取需要你授予 Android 權限，並啟用 Termux 的外部應用程式相關設定。Bibimer 使用該權限執行你請求的設定和開發操作。完成回覆的預覽不會儲存在橋接服務中繼資料檔案或一般紀錄中。

5. 保留、刪除與控制

應用程式設定和連線資訊會保留，直到你清除應用程式資料或解除安裝應用程式。橋接服務的近期輸出和排隊訊息僅儲存在執行中工作階段的記憶體中，可能隨程序終止或橋接服務重啟而消失。Termux 專案檔案、工作階段中繼資料和 AI 代理原生紀錄單獨儲存，其保留時間取決於你的操作和 AI 代理的保留設定。

在 Bibimer 清單中取消專案註冊或刪除已結束的工作階段，只會移除對應的 Bibimer 註冊資訊，不會刪除專案資料夾、Git 工作樹或 AI 代理原始紀錄。請使用 Termux 和相應 AI 代理刪除這些檔案和紀錄。解除安裝 Bibimer 不會移除它們。對於服務供應商持有的資訊，請直接向該服務供應商請求刪除。

Bibimer 不建立獨立的 Bibimer 使用者帳號。GitHub 和 AI 服務供應商帳號由相應服務管理。你可以在應用程式中斷開 Bibimer 與本機橋接服務的連線，並透過相應服務或工具撤銷外部服務的存取權限。

請求刪除資料或取得資料移除幫助

  1. 透過隱私申請表單說明要刪除的資訊。若表單無法使用，請寄送主旨為 Bibimer data deletion 的郵件至 andy@andineering.com。
  2. 請說明你的請求涉及應用程式設定、Termux 檔案、AI 代理或服務供應商紀錄，還是此前的支援郵件。請勿傳送密碼、API 金鑰或私密專案檔案。
  3. Andineering 處理其所持資訊（包括支援通訊紀錄）的相關請求，也可以說明如何移除本機資料。我們不持有你的 Termux 專案檔案或 AI 代理紀錄副本。請在裝置上刪除這些資料；對於服務供應商持有的資料，請直接向該服務供應商請求刪除。

裝置資料保留至你依上述方式刪除；外部服務自行規定記錄的保留期限。超過 90 天的網站詢問會透過定期清理從 D1 刪除。Discord 通知可能保留於私人支援頻道，直到營運者處理、刪除或回應刪除請求；不會在 90 天後自動刪除。申請刪除時請提供詢問編號。

6. 年齡範圍

Bibimer 面向 13 歲及以上使用者。外部 AI 代理、服務供應商和開發服務有各自的年齡及帳號要求，可能高於此年齡。

7. 網站代管

網站使用 Cloudflare Pages、Pages Functions 和 D1。Cloudflare 為提供及保護網站，處理 IP 位址、流量等請求資訊，可能在境外處理。詢問服務僅儲存用於防止濫用的金鑰式 IP 摘要，不儲存原始 IP。營運者未加入登入、廣告或分析指令碼；所選語言儲存在瀏覽器中。詳見 Cloudflare 隱私權政策。

取得提交前的同意後，聯絡表單會在 D1 儲存分類、自訂主題（如有填寫）、內容、選填回覆信箱、語言、提交時間及詢問編號，用於處理詢問。不提供附件或登入功能，也沒有公開讀取詢問的 API。詢問內容和選填信箱亦傳送至私人 Discord 支援頻道。Cloudflare 與 Discord 是外部處理服務，可能跨境處理資訊；另請參閱 Discord 隱私權政策。應用程式對話不會自動上傳。請勿提交密碼、API 金鑰、通行密鑰或私人專案檔案。

8. 聯絡方式與政策變更

查閱、更正或刪除資訊請使用隱私申請表單，上述信箱仍可作為備用聯絡方式。提交資訊用於回覆及處理申請，請只提供必要內容。處理方式改變時將更新政策與生效日期。
