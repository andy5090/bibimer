在手機上開始第一個專案

開始使用 Bibimer

請在同一部 Android 手機上安裝 Bibimer 和 Termux。Termux 執行開發工具並儲存專案檔案；Bibimer 透過行動介面集中管理專案、AI 代理工作階段、聊天和終端機。

在 Google Play 取得 Bibimer

本網站提供 10 種語言。目前 Google Play 正式版支援英文和韓文；其他應用程式語言正準備進行內部測試。本指南保留英文按鈕名稱，方便你在已發佈的應用程式中找到對應功能。

01安裝並開啟 Termux

請從 Termux 官方安裝指南列出的來源安裝。安裝後開啟一次，等待初始設定完成。

Termux 及其外掛程式應從同一來源安裝。按照本指南操作，無需另備開發電腦。

02將 Bibimer 連線到 Termux

在 Bibimer 中開啟 Setup → Manual setup and pairing → Save setup file。將檔案以 bibimer-setup.sh 的名稱儲存到 Android 的 Download 資料夾。

在 Termux 中執行以下指令，並授予檔案存取權限。如果已能存取 Download 資料夾，可跳過此指令。

termux-setup-storage

然後執行：

bash ~/storage/downloads/bibimer-setup.sh

腳本會按需安裝 Python，安裝本機 Bibimer 橋接程式並啟動它。將 Termux 中顯示的8 位數一次性配對碼輸入 Bibimer 的 Connect this app 區域。配對碼五分鐘內有效。

如果使用了其他檔名或儲存位置，請相應調整指令中的路徑。

03開啟專案並試用終端機

開啟側邊欄，選擇 Project Add。瀏覽 Termux 中的資料夾，或輸入 ~/projects/my-project 等路徑；如有需要，選擇建立資料夾，然後儲存專案。

選擇 Terminal 並啟動工作階段。輸入以下指令併傳送：

pwd

輸出會顯示手機上目前專案資料夾的路徑。完成這一步無需 AI 服務供應商帳號。

04按需新增程式開發代理

在 Termux 中準備相容的 Codex、Claude Code 或 OpenCode 安裝，並完成所需的服務供應商登入或 API 設定。然後在 Bibimer 中選擇 AI 代理並啟動工作階段。

可用模型和選項取決於安裝的 AI 代理。通用 Linux 安裝指南並不保證適用於 Android/Termux。服務供應商的費用和資料政策另行適用。

05管理你的工作

透過側邊欄切換專案、已有的 Git 工作樹和工作階段。Chat 顯示受支援 AI 代理的結構化回覆和核准請求；Terminal 提供命令列介面。開啟檔案總管，可查看專案檔案、Git 狀態和更改。

切換頁面或關閉 Bibimer 不會請求停止工作階段。Android 可能會停止背景程序；重啟橋接程式不會恢復已遺失的程序或終端機輸出。封存工作階段後，其任務仍會繼續執行。請在 Termux 中建立或刪除 Git 工作樹。

在 Settings → Language 中選擇應用程式顯示語言。輸入內容、專案名稱和終端機輸出不會被翻譯。

需要幫助？

如果連線失敗，請先確認 Termux 和橋接程式仍在執行。尋求幫助時，請說明進行到哪一步，並提供錯誤提示。請勿傳送密碼、API 金鑰或私有專案檔案。
