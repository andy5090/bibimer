Use Commit, Push, Pull and Sync in the sidebar Git views. Commit staged changes or choose to include all changes. Pull allows fast-forward updates only; Sync pulls before pushing. Update the Termux bridge to 0.24.0 in Settings to use Git actions. Terminal input and special keys now disable when the shell exits; its output stays available.
