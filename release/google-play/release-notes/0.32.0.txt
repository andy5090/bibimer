<en-US>
Terminal keys now fit two compact rows. Expand F1-F12 as a horizontal row.
Ctrl, Alt and Shift stay held until tapped again. Use Ctrl+C through the Ctrl key and keyboard.
Improved Shift combinations for Tab, arrows, function keys and ASCII input.
Fixed GitHub sign-in checks with older GitHub CLIs.
Update the Termux bridge to 0.23.1 in Settings for the GitHub fix.
