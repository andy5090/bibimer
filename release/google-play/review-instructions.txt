1. Open Bibimer and choose Try demo on the welcome screen, in Setup, or in Settings.
2. The Demo badge/banner identifies fictional sample replay. No account, Termux, payment, provider credential, location, or developer secret is required for this resource.
3. Open the sidebar or agent selector and choose Codex, Claude Code, OpenCode, or Terminal. They show invented examples shaped after structured event formats, never actual session transcripts.
4. Send arbitrary text to advance the examples. Chat/terminal input is ignored and not retained in sample logs. The first two sends finish automatically; every third send requests sample approval and then a question. Accepting does not run a command. Question answers are discarded.
5. Explore sample projects/worktrees/session management, model choices, queue/Steer controls, file previews, Git status/diffs/history, conversation handoff, session import, and fictional GitHub import. Sample operations remain in memory and do not read or change device project files.
6. In Settings enable response notifications and permit Android notifications. Start an automatic example and return Home. The ongoing foreground notification and completion notification say Demo. Tap completion to open its sample session. Turn off alerts from the ongoing notification or Settings.
7. Exit demo returns to normal setup. Demo preferences are separate; existing normal connection/settings are preserved. Unsent normal drafts are temporarily held in process memory and restored when returning without process death. Sample workspace resets on exit or process restart.

External integration scope:
Bibimer is an Android development environment for user-owned Termux tools. Real shell/agent work requires Termux on the same device, a local bridge, compatible installed CLIs, and any independently configured third-party accounts. The demo gives account-free interface access; it does not run or verify live AI inference, GitHub authentication, Git operations, or Termux commands. No developer's personal agent or GitHub credentials are provided.
