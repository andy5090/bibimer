# 지원 언어 확대

## 우선순위 (2026-10-14)

현재 공개 0.17.1은 영어·한국어를 제공한다. 사용자와 우선순위를 검토한 뒤 **스페인어·중국어 간체를 최우선**, 이어 **브라질 포르투갈어·중국어 번체·러시아어**로 정했다. 인도네시아어·일본어·독일어·프랑스어는 다음 묶음이다. 출시 순서와 현재 구현된 번역을 구분한다.

| 우선순위 | 언어 | 선정 이유와 검증할 가설 |
| --- | --- | --- |
| 최우선 | 스페인어 (`es`) | 중남미 여러 국가와 스페인에 적용할 수 있는 범위가 크다. 특정 국가의 구어체를 피한 공통 표현부터 시작한다. |
| 최우선 | 중국어 간체 (`zh-Hans`) | 큰 중국어 개발자·사용자층을 고려한다. 국가별 Play 유통 범위와 중국어 사용자를 동일시하지 않는다. 간체·번체는 별도 번역으로 관리한다. |
| 다음 | 브라질 포르투갈어 (`pt-BR`) | 브라질의 개발자 규모와 성장세를 반영한다. 포르투갈어 개발자가 중국어·스페인어 개발자보다 많다는 주장은 하지 않는다. |
| 다음 | 중국어 번체 (`zh-Hant`) | 번체 사용자에게 맞는 개발 용어를 제공한다. 간체를 글자만 치환한 번역으로 처리하지 않는다. |
| 다음 | 러시아어 (`ru`) | 러시아어권 개발자와 여러 지역의 이용자를 고려한다. 러시아어가 세계 화자 수 3위라는 가정은 사용하지 않는다. |
| 후속 | 인도네시아어 (`id`) | 성장하는 개발자 커뮤니티에서 폰 자체 개발 흐름의 수요를 검증한다. |
| 후속 | 일본어·독일어·프랑스어 | 개발자·AI 도구 사용층과 지원 문의를 보고 순서를 조정한다. |

초기에는 브라질의 성장세를 크게 반영해 포르투갈어·스페인어·인도네시아어부터 작업했다. **중국어를 후순위에 둔 판단은 수정했다.** 기존 세 언어에 중국어 간체 소스를 추가했다. 다음 대상은 중국어 번체·러시아어다. 개발 소스와 공개 앱의 지원 언어를 구분하며, 새 앱 언어는 아직 배포하지 않았다.

GitHub Octoverse 2025의 국가별 개발자 규모에서는 중국이 브라질보다 앞서며, 브라질 약 689만 명·인도네시아 약 437만 명의 계정과 성장세를 보고한다. 이는 **국가별 GitHub 활동의 대리지표**로, 언어별 개발자 수·Android/Termux 이용자 수·Bibimer 전환율을 나타내지 않는다. 순위는 이 자료와 언어권 도달 범위·제품 특성·번역 유지 비용을 종합한 제품 판단이다. [GitHub 공식 보고서](https://github.blog/news-insights/octoverse/octoverse-a-new-developer-joins-github-every-second-as-ai-leads-typescript-to-1/).

세계 화자 수는 모국어/제2언어 포함 여부와 언어 분류에 따라 달라진다. 예를 들어 Cervantes 2025 보고서는 자체 인도 인구 추계와 언어 범위를 적용해 모국어 집단을 중국어·힌디어·스페인어 순으로 설명한다. 서로 다른 기관의 숫자로 하나의 순위를 만들지 않는다. 중국어·스페인어의 큰 규모는 지원을 앞당길 근거지만, 언어별 실제 전환율은 별도로 확인한다. [Cervantes 2025 보고서](https://observatoriodelespanol.cervantes.org/wp-content/uploads/2025/10/Spanish_a_language_to_the_world_2025.pdf).

힌디어·벵골어·베트남어·튀르키예어·아랍어도 후속 후보로 둔다. 인도는 여러 언어를 사용하므로 국가 규모만으로 힌디어 수요를 가정하지 않는다. 아랍어는 RTL UI와 LTR 코드·경로·터미널 혼합 검증을 별도로 수행한다. 지원하지 않는 언어의 영어 fallback은 유지한다.

## 출시 순서와 측정

1. 앱의 화면·설치 안내·오류·접근성 레이블과 Android 알림을 번역한다. 영어 원문과 자리표시자·명령·권한 의미를 대조한다.
2. 개발 소스에서 언어 전환·재시작 후 선택 유지·좁은 화면·기존 영어/한국어 회귀를 확인한다. 번역은 AI 초안이며 원어민 검수 완료로 표시하지 않는다.
3. 다음 명시적 APK/AAB 빌드 요청에 반영해 내부 테스트한다. Android WebView·실제 알림·시스템 Back·설치 파일 동작을 확인한다.
4. 앱 출시에 맞춰 해당 언어의 Play 등록정보·스크린샷을 추가한다. 웹사이트/설치 안내 번역은 먼저 제공할 수 있지만 공개 앱의 실제 언어 범위를 명시한다. 앱에 아직 배포되지 않은 언어를 스토어나 공개 홈에서 지원 완료로 광고하지 않는다. 웹사이트는 기존처럼 언어별 URL과 자체 언어 선택 UI를 사용한다.
5. 출시 후 충분한 관측 기간(예: 4주)을 두고 Play Console에서 제공되는 국가/언어별 방문·설치·전환 정보와 지원 문의를 검토한다. 표본이 작으면 순위를 단정하지 않는다. 이 작업을 위해 새 분석 SDK나 사용자 대화 수집을 추가하지 않는다.

## 구현 규칙

- `i18n.js`의 기존 영어·한국어 사전을 기준으로 새 언어는 `i18n-<locale>.js`에 분리한다. 새 라이브러리·번역 네트워크 요청은 없다. 모든 카탈로그를 런타임보다 먼저 로드하고 Android asset 허용 목록에도 등록한다.
- Android `AppLanguage`는 여섯 언어 또는 `system` 설정을 저장한다. 저장값이 없거나 유효하지 않으면 기기 언어 우선순위에서 지원 언어를 찾고, 없으면 영어를 사용한다. 기존 명시적 영어 선택은 유지한다. 저장 실패는 현재 선택을 바꾸지 않는다.
- 네이티브 문자열은 `values-pt-rBR`, `values-es`, `values-in`, `values-b+zh+Hans`에 둔다. 앱의 인도네시아어 언어 태그는 `id`다. AAB의 기존 LANGUAGE split 비활성화를 유지해 기기 언어와 무관하게 앱 안에서 선택할 수 있게 한다.
- 누락된 번역은 영어로 돌아가지만, 릴리스 검사에서는 누락·빈 문자열·중복 키·자리표시자 차이를 실패로 처리한다. `{path}`, `{account}` 등 사용자 값을 그대로 삽입한다.
- 프로젝트 이름·사용자 입력·에이전트 응답·코드·파일·터미널 출력은 번역하지 않는다. 심사용 가상 로그도 기존 영어/한국어 예제를 유지한다. 앱의 설치 안내는 번역하지만 Termux 셸 설치기 출력은 기존 영어/한국어 범위다.
- Android 언어 리소스와 기본 문자열의 완전성을 검사한다. [Android 공식 현지화 안내](https://developer.android.com/guide/topics/resources/localization).

## 검증 명령

```sh
node scripts/tests/test_i18n.cjs
python3 -m unittest discover -s scripts/tests -p 'test_app_language.py'
python3 -m unittest discover -s scripts/tests -p 'test_build_release.py'
```

카탈로그 검사는 번역의 자연스러움을 보증하지 않는다. 특히 권한·승인·취소·삭제·세션 종료·외부 서비스 비용 문구는 의미 검토와 실제 화면 확인을 함께 수행한다.

## 이번 소스 검증 결과

2026-10-14: 세 새 언어 각각 580개 앱 문구와 21개 네이티브 문자열을 준비했다. 전체 키/자리표시자 검사, Python 16개와 기존 Node 회귀, AAPT2 리소스·전체 Java 컴파일을 통과했다. 320/393px에서 첫 화면·설치 안내·설정, 1600px 설정을 확인했고 키보드 선택·Escape·저장 후 reload·초안/프로젝트 유지도 확인했다. 시각 판정 95점 pass. 스크린샷은 로컬 `dist/localization/`에 있다.

공개 0.17.1의 언어는 여전히 영어·한국어다. 실제 Android 설치/알림 검증·원어민 검수·중국어 번체/러시아어 구현·스토어 언어 추가는 후속이며, APK/AAB를 만들거나 배포하지 않았다. 중국어 간체와 웹사이트 후속 작업 기록은 NEXT_SESSION.md를 따른다.


## 중국어 간체·웹사이트 후속 완료

2026-10-14: `zh-Hans` 580개 UI·21개 네이티브 문구를 추가해 개발 소스는 6개 언어다. Node 전체 키/자리표시자, Python 17개, AAPT2·Java 컴파일과 중국어 첫 화면/설정/설치 안내의 320/393px 표시·저장 후 reload·Escape를 확인했다. Android 설치본을 빌드하지 않았다.

웹사이트는 같은 6개 언어의 홈·전체 정책을 별도 URL로 제공하며 Cloudflare에 배포했다. 공개 앱은 EN/KO라는 안내를 유지한다. 앱의 정책 버튼도 선택 언어 URL을 사용하도록 소스에 반영했다. 12개 공개 페이지 원본·보안 헤더, 모바일 2개 폭·키보드 언어 이동을 검증했다. 배포 및 증빙은 `release/website/README.md`, `NEXT_SESSION.md`에 기록한다.
