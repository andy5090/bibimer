2026-10-11 운영 주체·지원 이메일·13세 이상 대상 연령을 사용자에게 확인하고 [영어 웹 정책](../release/website/public/privacy/index.html)과 [한국어 웹 정책](../release/website/public/ko/privacy/index.html)을 Cloudflare Pages에 게시했다. 공개 주소는 영어 https://bibimer.app/privacy/, 한국어 https://bibimer.app/ko/privacy/ 이며 언어 전환으로 같은 정책의 다른 언어 페이지를 연다. 이 Markdown 파일은 작업 근거 문서이며 공개 정책은 웹 페이지를 기준으로 한다. `bibimer.app`은 사용자 구매 지시 후 Cloudflare에 1년 등록·연결했다. 앱 Settings의 정책 열기 버튼을 캡처용 APK에 포함했고 에뮬레이터에서 외부 Chrome 실행을 확인했다. Chrome 최초 실행 약관 단계 이후의 페이지 로드와 실기기 확인은 남았다.

## 앱과 Termux에서 처리하는 정보

BIBIMER는 같은 Android 휴대폰의 Termux에서 프로젝트와 사용자가 선택한 코딩 에이전트 세션을 관리하는 모바일 에이전트 개발 환경(ADE)이다. 프로젝트 이름·폴더 경로, 세션 정보, 입력·답변, 터미널 및 도구 출력을 표시하고 입력을 전달한다. Android 앱과 Termux 브리지는 같은 기기의 로컬 주소로 통신한다.

앱은 언어·입력·에이전트·알림 설정과 연결 정보를 앱 전용 저장소에 보관한다. 연결 토큰은 Android Keystore를 이용해 암호화한다. 프로젝트·세션 목록, 에이전트의 원본 세션 식별자 등은 Termux의 권한을 제한한 폴더에 보관한다. BIBIMER 운영 서버로 대화를 업로드하는 기능이나 광고·분석 SDK는 현재 앱에 포함되어 있지 않다.

## 에이전트와 외부 서비스

사용자가 지시를 보내면 선택한 에이전트는 사용자의 입력과 작업에 필요한 코드·파일·대화 맥락을 설정된 AI 제공자 또는 도구 서비스로 전송할 수 있다. 해당 데이터의 사용·보관은 사용자가 선택한 에이전트, 제공자, 계정, 권한 및 설정에 따라 달라진다. BIBIMER의 로컬 연결만으로 모든 작업이 기기 안에서 처리된다는 뜻은 아니다.

다른 에이전트로 대화를 전달하는 경우 사용자가 미리보기를 확인·편집하고 전송한 맥락과 다음 지시가 대상 에이전트로 전달된다. 전달 본문은 대상 에이전트의 기록에 남을 수 있다.

Termux 및 개발 도구 설치, 패키지 저장소 접속, 외부 안내 링크를 열 때 해당 배포처·웹사이트가 요청을 처리한다. 사용자는 외부 서비스의 개인정보처리방침과 설정을 확인할 수 있다.

## GitHub 연결과 파일 열기

GitHub 저장소 가져오기는 Termux의 GitHub CLI로 인증하고 접근 가능한 저장소를 조회한 뒤 선택한 폴더에 클론한다. 자격 증명은 GitHub CLI가 관리한다. 앱에는 계정 상태·저장소 정보와 필요한 일시적 로그인 코드를 표시하며 인증 토큰을 WebView나 일반 로그에 전달하지 않는다. 클론한 파일은 선택한 폴더에 남는다.

프로젝트 또는 Download 파일을 다른 Android 앱으로 열면 앱 전용 캐시에 임시 복사본을 만들고 선택한 뷰어에 임시 읽기 권한을 부여한다. 뷰어는 자신의 처리 방침에 따라 파일을 사용한다. 복사본 수정은 원본 프로젝트에 반영되지 않으며 캐시는 용량·만료 제한에 따라 이후 앱 사용 또는 연결 해제 때 정리한다.

## 저장 기간과 삭제

앱 설정과 연결 정보는 앱 데이터 삭제 또는 앱 제거 시 삭제된다. Termux의 프로젝트·세션 메타데이터와 에이전트 원본 대화 기록은 별도로 보관된다. 앱 제거만으로 Termux 파일이나 외부 제공자의 데이터를 삭제하지 않는다.

브리지는 최근 출력을 제한된 메모리에 유지하고 대기 입력도 실행 중인 해당 세션에 보관한다. 프로세스 종료나 브리지 재시작 시 이 임시 내용이 사라질 수 있다. 에이전트 자체가 저장한 원본 기록은 에이전트의 보관 정책을 따른다.

프로젝트 등록 해제와 종료된 세션의 목록 삭제는 BIBIMER의 등록 정보만 제거한다. 실제 프로젝트 폴더·Git 워크트리·에이전트 원본 기록을 지우지 않는다. 실제 파일과 원본 기록 삭제는 Termux 및 각 에이전트에서 별도로 수행한다. 외부 AI 제공자에 보관된 데이터의 삭제는 해당 서비스에서 요청한다.

2026-10-12 공개 정책의 `#data-deletion`에 이메일 삭제 요청 단계와 보관 범위를 구체화했다. 제목 **Bibimer 데이터 삭제**로 `andy@andineering.com`에 삭제할 정보의 종류를 알려 달라고 안내한다. 운영자가 보유한 문의 이메일 등은 직접 처리하고 기기 데이터는 삭제 방법을 안내한다. 운영자는 Termux 프로젝트·에이전트 원본 기록 사본을 보유하지 않는다. 비밀번호·API 키·비공개 프로젝트 파일을 요청하지 않는다. 문의 이메일은 요청 해결이나 법적 의무 이행에 필요한 동안 보관하고 같은 이메일로 삭제를 요청할 수 있다. 이 안내는 기존 처리 구조를 바꾸지 않는다.

## 권한과 알림

Termux 명령 실행에는 Android 권한과 Termux 외부 앱 연동 허용이 필요하다. BIBIMER는 사용자가 선택한 설정·개발 작업을 이 권한으로 전달한다.

응답 완료 알림에는 프로젝트·세션 이름과 답변 앞부분 최대 180자가 표시될 수 있다. 알림의 공개 잠금 화면 버전에는 일반 완료 문구를 사용한다. Android 알림 표시 및 알림 접근 권한을 받은 다른 앱 등 기기의 설정에 따라 내용에 접근할 수 있다. 앱 설정이나 지속 알림에서 감시를 끌 수 있다. 미리보기는 브리지 메타데이터 파일이나 일반 로그에 저장하지 않는다.

## 문의와 변경

Bibimer는 13세 이상 사용자를 대상으로 한다. 외부 에이전트·제공자·개발 서비스의 연령·계정 요건은 별도이며 더 높은 연령을 요구할 수 있다.

개인정보 문의와 열람·정정·삭제 요청은 웹사이트 문의 양식의 개인정보 카테고리로 받고, 양식을 사용할 수 없을 때를 위해 andy@andineering.com을 대체 연락처로 유지한다. 문의 접수 번호로 이전 문의를 지정할 수 있다. 운영자는 자신이 보유한 문의를 처리하고 Termux 원본 파일은 기기에서 삭제하도록 안내한다. 처리 방식이 바뀌면 공개 10개 언어 정책과 시행일을 함께 갱신한다.

## 웹사이트 호스팅

웹사이트는 Cloudflare Pages에서 제공한다. Cloudflare는 전송과 보호를 위해 IP 주소·트래픽 정보 등 접속 요청 정보를 처리하며 해외 인프라에서 처리할 수 있다. [Cloudflare 개인정보처리방침](https://www.cloudflare.com/privacypolicy/)을 웹 정책에서 연결했다. 운영자가 추가한 로그인·광고·분석 스크립트는 없으며 선택한 언어를 브라우저에 저장한다. 문의 양식은 아래와 같이 별도로 처리한다.

## 웹사이트 문의 양식 (2026-10-19)

- 제출 전 개인정보 처리 동의를 받고 카테고리·직접 입력한 문의 유형·내용·선택 입력한 회신 이메일·언어·접수 시각·접수 번호를 Cloudflare Pages Functions에서 처리해 D1에 저장한다. 로그인·첨부파일 기능이나 문의를 공개 조회하는 API는 제공하지 않는다. 앱 대화를 자동 업로드하지 않는다.
- 문의 내용과 선택 입력한 이메일은 운영자의 비공개 Discord 지원 채널에도 전달한다. 웹훅은 서버 비밀 설정에 보관하며 공개 HTML·JavaScript·저장소에 포함하지 않는다. Cloudflare·Discord의 해외 인프라 처리 가능성과 각 개인정보처리방침을 공개 정책에 명시한다.
- 남용 방지를 위해 키 기반 IP 해시만 별도 저장하며 문의 서비스가 IP 원문을 저장하지 않는다. Cloudflare 자체의 일반 접속 요청 처리와는 구분한다. 비밀번호·API 키·패스키·비공개 프로젝트 파일을 보내지 않도록 안내한다.
- 90일이 지난 문의는 D1에서 정기적으로 삭제한다. Discord 알림은 운영자가 처리·삭제하거나 개인정보 삭제 요청에 대응할 때까지 비공개 지원 채널에 남을 수 있다. Discord 메시지를 90일 뒤 자동 삭제한다고 약속하지 않는다.
- 개인정보·삭제 요청의 기본 경로는 언어별 `/contact/?category=privacy`다. 공개 정책은 기존 8개 절을 유지하면서 보관·삭제·웹 호스팅·문의 절을 수정하고 시행일을 2026-10-19로 갱신했다. 배포·실제 보관 정리 검증 결과는 NEXT_SESSION.md를 기준으로 확인한다.
