# 음성 입력 설정

내부 테스트 Android0.38.2(64)에 반영한 기능이다. 실제 기기의 업데이트 수신/설치나 제공자 계정으로의 변환 성공을 확인했다는 뜻은 아니다. Termux 브리지 업데이트는 필요하지 않다.

## 사용 흐름

마이크를 누르면 중복 실행을 막고 선택한 음성 입력 화면을 연다. 입력창의 별도 ‘음성 입력을 여는 중’ 문구는 표시하지 않으며, 녹음·변환 진행과 오류는 필요한 화면에서 안내한다.

설정 → 음성 입력에서 기기 기본값, 설치된 호환 음성 입력 앱, OpenAI 또는 ElevenLabs를 선택한다. 기본값은 기존 Android 음성 입력이다. Android 전체의 기본 앱 설정은 변경하지 않는다. 앱 목록은 `ACTION_RECOGNIZE_SPEECH` 화면을 실제로 제공하는 앱만 조회하며, 시스템 인식 서비스나 키보드 전용 엔진 전체를 지원한다고 표시하지 않는다. 선택한 앱을 삭제하면 ‘선택한 앱을 사용할 수 없음’으로 표시하며 다른 앱을 자동 실행하지 않는다.

인식 언어는 제공자 기본값/자동 감지 또는 지원하는 언어 중 선택한다. 앱 표시 언어와 별도로 저장한다. 기기 앱은 지정한 언어 힌트를 자체 지원 범위에서 처리하고, 외부 API에는 선택한 언어만 힌트로 전달한다. 기기 음성 입력 앱은 자체 정책에 따라 네트워크를 사용할 수 있다.

외부 제공자는 본인의 API 키를 등록해야 한다. 현재 고정 모델은 OpenAI `gpt-transcribe`, ElevenLabs `scribe_v2`이며 선택 목록에 모델명을 표시한다. API 요금과 제공자 데이터 보관 정책은 해당 계정에 적용된다. 다른 제공자나 기기 입력으로 자동 재시도하지 않는다.

외부 API를 선택하고 입력창의 마이크를 누르면 필요한 경우 Android 마이크 권한을 요청한다. 녹음은 최대 60초이며 ‘녹음 마치기’를 누른 뒤 별도의 ‘전송해 변환’ 확인을 거쳐야 업로드한다. 길이 제한에 도달해도 자동 전송하지 않는다. 취소하면 녹음을 버린다. 앱이 숨겨지면 녹음·진행 중 요청을 취소하며 백그라운드 녹음을 제공하지 않는다. 이미 제공자에게 도착한 오디오는 취소로 회수할 수 없다.

변환 결과는 시작 당시 초안의 커서/선택 영역에 삽입한다. 자동 전송·대기열 추가·Steer·터미널 입력은 하지 않는다. 초안 편집, 세션/프로젝트/탭 변경, 입력 비활성화는 외부 요청을 취소하며 늦은 결과를 삽입하지 않는다. 실패하면 초안을 유지하고 사용자가 재시도한다.

## 키·오디오 처리

- 키 입력·녹음·전송 확인·변환 진행 창은 앱의 색상·입력 테두리·버튼을 적용한 자체 `BibimerDialog`로 제공한다. API 키는 이 자체 UI 안의 Android 네이티브 비밀번호 필드로 처리하며 WebView나 Termux로 키를 전달하지 않는다. 자동 완성·화면 상태 저장·IME 전체 화면 편집/개인화 학습을 끄고 키 입력 창에 `FLAG_SECURE`를 적용한다. 저장·취소·앱 숨김·오래된 요청 폐기 시 입력을 비우고, 기존 키는 입력 필드에 다시 표시하지 않는다. 오류는 자체 인라인 안내로 표시한다.
- 제공자별로 분리된 Android Keystore AES-GCM 키와 앱 전용 암호화 설정을 사용한다. 브리지 인증 토큰과 저장 영역·별칭을 공유하지 않는다. WebView에는 키 등록 여부만 전달한다. 설정에서 키를 교체하거나 삭제할 수 있다.
- AAC/M4A 녹음은 앱 내부 캐시 임시 파일로 만들고 취소·완료·실패 시 지운다. 비정상 종료 잔여 파일은 다음 앱 시작 때 정리한다. 백업은 기존 앱 설정대로 비활성화되어 있다.
- 앱·브리지의 일반 로그나 프로젝트 파일에 키·오디오·원본 API 응답을 기록하지 않는다. 인식 텍스트는 일반 초안으로만 처리한다. 사용자가 나중에 전송한 텍스트는 기존 대화 저장 규칙을 따른다.
- 네이티브 HTTP 요청은 고정 HTTPS 호스트만 사용하며 리디렉션·자동 재시도·제공자 대체를 하지 않는다. 요청 오디오 8MiB, 응답 1MiB, 변환 텍스트 65,536자로 제한하며 오류 응답 본문을 UI에 노출하지 않는다. 연결 15초·응답 읽기 60초 제한과 취소 시 연결 종료를 적용한다.

## 연결 확인의 범위

연결 확인은 녹음이나 유료 음성 변환 요청 없이 실행한다. OpenAI는 선택한 모델의 메타데이터, ElevenLabs는 사용자 조회 API를 호출한다. 성공은 해당 API 접근 확인이며 음성 변환 잔액·모든 권한 확인이 아니다. ElevenLabs 사용자 조회 권한이 제한된 키는 확인에 실패해도 음성 변환 권한이 있을 수 있다. 확인 실패를 이유로 키를 삭제하거나 제공자를 바꾸지 않는다. 계정 본문은 저장하거나 표시하지 않는다.

## 검증과 배포 전 확인

API 전송 형식·취소·오류·제한 검사, Android 모의 객체 기반 녹음 권한/수명/정리/명시적 전송 흐름 검사, 실제 API 36 전체 Java 컴파일, 초안 격리·설정 UI·10언어 회귀를 수행한다. 모의 객체는 실제 Android WebView·마이크·인식 제공 앱을 대체하지 않는다.

실제 단말의 권한 허용/거절/다시 묻지 않음, 녹음 시간 제한·취소·앱 숨김·복귀·프로세스 종료, 작은 화면·큰 글꼴·TalkBack, Android Keystore 재실행·키 교체/삭제를 확인해야 한다. 실제 계정으로 OpenAI/ElevenLabs 언어별 변환·제한된 키·한도/네트워크 오류도 확인해야 한다. 이번 소스 작업에서는 사용자 키를 읽거나 유료 API를 호출하지 않는다. APK/AAB 빌드 및 배포 전에는 기존 공개 개인정보 안내와 Play 데이터 관련 신고가 선택적 오디오 외부 전송을 정확히 설명하는지 검토·반영해야 한다.

## 답변 음성 읽기(TTS)

TTS도 다음 앱 빌드용 소스다. 설정 → 답변 음성 읽기의 **자동 읽기는 기본 꺼짐**이며 기존 설치에서도 저장된 값이 없으면 꺼진다. Android TTS·ElevenLabs, Android 엔진, 해당 제공자의 음성, 전체 답변/기기 내 요약을 각각 선택해 저장한다. 모든 선택 목록은 기존 앱의 아웃라인이 있는 하단 시트를 사용한다. TTS 키는 음성 입력 키와 별도의 네이티브 암호화 저장소·별칭을 사용하며 자동으로 복사하지 않는다.

- Android는 `TextToSpeech`의 엔진·음성 목록을 조회한다. 음성 이름·언어·네트워크 필요 여부를 표시하고 데이터 설치가 필요한 음성은 비활성화한다. 선택한 엔진이 없어졌을 때 생성자가 기본 엔진으로 자동 대체하지 않도록 사전 확인한다. 기본 엔진/음성은 Android와 앱 언어의 지원 범위를 따른다. 엔진 자체가 네트워크를 사용할 수 있으므로 Android TTS 전체를 오프라인으로 보장하지 않는다.
- ElevenLabs는 `eleven_multilingual_v2`로 합성하고 사용자의 `/v2/voices` 목록을100개씩 명시적으로 불러온다. 사용자가 ‘더 보기’를 누르면 다음 페이지를 조회한다. 원본 계정 보고·음성 샘플·미리듣기 URL을 저장하거나 실행하지 않고 음성 ID·이름만 화면용 메모리에 보관한다. 선택한 ID만 설정에 저장한다. 앱 재실행 후 저장된 ID로 합성할 수 있지만 제공자가 거절하면 중지한다.

자동 읽기는 현재 표시 중인 Chat에서 브리지가 전달한 **명시적인 정상 완료 turn 항목**을 사용한다. 같은 턴의 완료된 `final_answer`를 우선하며 단계 구분이 없으면 마지막 완료된 assistant 답변을 사용한다. 도구·명령·추론·사용자 메시지·PTY 출력이나 단순히 ready로 바뀐 상태를 읽지 않는다. 최초 스냅샷과 출력 gap은 자동 읽기를 건너뛰고 완료 ID로 중복을 막는다. 가져온 대화는 자동 재생하지 않는다. 앱이 표시되지 않는 동안 소리를 내는 백그라운드 TTS 서비스는 추가하지 않았다. 처음 연 세션에서 첫 스냅샷 전에 이미 완료한 답변은 자동 읽기를 생략할 수 있다.

TTS가 켜진 Chat의 완료된 각 답변에 재생 아이콘을 제공한다. 이전 답변도 해당 아이콘으로 다시 읽으며 전체/요약 모드는 저장한 설정을 따른다. 자동 읽기·수동 재생과 합성 준비 중에는 해당 답변의 같은 아이콘이 정지로 바뀌고 누르면 취소한다. 다른 답변을 재생하면 앞선 읽기를 중지한다. 별도의 ‘최근 답변 읽기’·‘읽기 중지’ 버튼은 제공하지 않는다. 설정의 자동 읽기는 자체 토글 스위치로 제공한다. 꺼져 있으면 제공자·음성·전체/요약·API 키·미리듣기 등의 하위 설정을 비활성화하고 흐리게 표시한다. 저장된 선택과 키는 유지하며 다시 켜도 과거 답변을 자동 재생하지 않는다. ‘음성 미리듣기’는 기능을 켠 뒤 사용자가 직접 실행한다. 미리듣기는 앱의 고정 예문만 합성하며 실행 중에는 같은 미리듣기 버튼으로 중지한다. 앱 숨김·세션/탭/프로젝트 변경·설정 변경·오디오 포커스 상실·음성 입력 시작 시 합성과 재생을 취소한다. 마이크가 사용 중이면 새 읽기를 시작하지 않는다. 중지된 읽기는 자동 재개하지 않는다. 다음 답변이 완료되면 앞선 읽기를 중지하고 새 답변을 읽는다. 다른 세션 답변을 읽기 대기열에 쌓지 않는다.

전체 답변은 서식 기호를 정리하고 코드 본문·변수명 등 실제 텍스트를 유지해 안전한 경계로 최대2,000자씩 나눠 순차적으로 읽는다. 외부 제공자에는 재생할 다음 조각 하나씩만 요청한다. 기기 내 요약은 코드 블록·표를 제외한 문장에서 반복 주제와 위치를 바탕으로 핵심 문장 최대3개·약700자를 추출한다. 새 문장을 생성하는 AI 요약이 아니며, 중요한 세부 내용이 빠질 수 있음을 설정에 알린다. 원래 답변은 수정하지 않는다. 요약을 위한 모델 호출이나 사용자 대화 전송을 추가하지 않는다.

외부 TTS를 선택하면 전체/요약 모드에 따라 **읽을 텍스트**가 제공자에게 전송되고 미리듣기도 요금이 발생할 수 있음을 안내한다. 합성 음성임을 명시하며 제공자의 보관 정책이 적용된다. 키·읽을 답변·요약·원본 오류를 일반 로그/프로젝트 파일/브리지에 저장하지 않는다. 외부 음성은 앱 전용 임시 MP3로 재생하고 완료·취소·실패에 삭제하며 비정상 종료 잔여 파일은 다음 시작 때 정리한다. 이미 제공자에게 전달된 텍스트는 취소로 회수할 수 없다. 오류 응답 본문을 UI에 노출하거나 다른 제공자로 자동 재시도하지 않는다.

검증은 `test_speech_output.cjs`(UI·완료 선택·중복·이력 제외), `test_speech_output_api.py`(고정 목적지·인증·오디오·페이지·요약/분할), `test_speech_output_controller.py`(Android 모의 엔진·기본 꺼짐·순차 재생·포커스·취소·파일 정리), 전체 API36 Java 컴파일,912키×10언어 및 기존 Chat/음성 입력 회귀로 진행한다. 실제 TTS 엔진·스피커/이어폰·포커스·음성 다운로드·백그라운드/멀티윈도·WebView/TalkBack·실제 제공자 권한/유료 합성은 APK 설치 후 검증해야 한다. 배포 전 개인정보 안내/Play 데이터 신고에는 선택적 답변 텍스트 전송도 반영해야 한다.
