# 작업 중심 화면과 초기 설정

2026-11-05 내부 테스트0.38.0(62)에 반영한 화면 기준이다. 정식0.35.1 등 이전 설치본의 하단 작업·준비·설정 탭과 구분한다.

작업을 기본 화면으로 사용하며 하단 탭은 없다. 상단 설정 버튼으로 앱 설정을 열고 상단 뒤로 가기·Android Back·외장 키보드 Escape로 이전 화면에 돌아간다. 열린 다이얼로그는 먼저 닫으며 IME 조합 중 Escape로 화면을 닫지 않는다. 작업 화면으로 돌아오는 동작은 세션을 실행하거나 종료하지 않는다.

## 첫 실행과 기존 연결

- 저장된 연결 정보가 없으면 초기 준비 안내로 시작한다. Termux 설치·권한·브리지 연결·선택적인 에이전트 설치와 계정 연결을 안내한다. 터미널 사용에 에이전트 계정을 요구하지 않는다.
- 연결 정보가 있으면 실제 브리지 연결이 잠시 끊겨 있어도 작업 화면에서 재연결을 시도한다. 연결 정보가 있다는 사실만으로 준비가 검증됐다고 표시하지 않는다. 준비 안내의 연결 완료 표시는 기존처럼 실제 정상 연결 상태를 사용한다.
- 수동 페어링이나 빠른 연결이 성공하면 작업 화면으로 돌아간다. 계정별 모델 사용 가능 여부를 추측하거나 에이전트를 자동 실행하지 않는다.
- 연결 해제는 설정에서 제공한다. 앱의 연결 정보를 지우고 초기 준비 안내로 이동하되 Termux의 브리지나 실행 세션은 종료하지 않는다.

## 설정에서 관리

설정에는 브리지 업데이트/재시작, 재연결/앱 연결 해제, 에이전트 계정/프로바이더/API 키, 입력·언어·알림·음성 설정을 둔다. 초기 준비 화면의 별도 로그인·상태·버전 버튼을 반복하지 않고 에이전트별 ‘연결 관리’에서 설정과 같은 관리 다이얼로그를 연다. 설치·복구·어댑터 준비처럼 Termux에 필요한 작업은 설치 안내에 남긴다.

‘초기 설정 가이드’로 준비 안내를 다시 열 수 있다. 에이전트 관리 옆 설치 안내는 선택한 에이전트의 설명을 펼친다. 설정에서 가이드를 열고 뒤로 가면 설정의 이전 스크롤 위치로 돌아가며 다시 뒤로 가면 작업으로 돌아간다. 알림이나 프로젝트/세션 선택으로 작업에 직접 이동하면 보조 화면의 이전 경로를 비운다.

새 화면에서 브라우저 제어는 작업 화면의 요청 카드 또는 **상단 설정 → Firefox · Termux:X11 → 로그인 및 에이전트 제어**에서 사용자가 허용한다. 하단 탭이 있는 기존 설치본은 **하단 설정 → Firefox · Termux:X11 → 로그인 및 에이전트 제어**를 사용한다. 화면을 여는 것만으로 제어를 허용하지 않는다.

## 상태와 검증

페이지 이동은 기존 세션·네이티브 대화·작성 초안·대기열을 유지한다. 터미널 입력은 작업 화면에서만 활성화하며 기존 전체 화면 동작과 정상 완료 알림의 세션 이동을 유지한다. 넓은 화면의 프로젝트/파일 패널은 보조 화면에서 가리고 작업으로 돌아오면 기존 열림 상태로 표시한다.

`scripts/tests/test_page_navigation.cjs`에서 최초 진입·기존 연결/데모·뒤로 가기·가이드 스크롤 복원·세션/초안/대기열 유지·공유 관리 진입점을 검증한다. 전체 언어 검사는 새 문자열과 10개 언어 카탈로그를 확인한다. 관리 Firefox의 모의 화면은 `dist/navigation/`에 기록하며 Android WebView의 실기기 화면·키보드·TalkBack·알림 탭 동작 검증을 대체하지 않는다.
