    GET YOUR PHONE READY

    A workspace on your phone.

    Follow these steps to install Termux and connect the app.

    1

    Install Termux

    Checking

    Termux stores your projects and runs development commands on this phone. Open it once after installation to finish its initial setup.

    Use the same distribution source for Termux and its plugins. Complete installation on the linked page and in Android's installer.

    2

    Connect with Termux

    Install the bridge if needed, start it, and connect automatically.

    First-time permissions

    Allow BIBIMER to run commands in Termux when Android asks. Enable external apps in Termux once using the command below, then return and connect.

    Manual setup and pairing

    Set up the bridge

    Save the setup file as bibimer-setup.sh in your Download folder. It connects this app to Termux.

    Run these commands one at a time in Termux. Finish granting file access before running the installation command.

    termux-setup-storage
    bash ~/storage/downloads/bibimer-setup.sh

    The setup file installs Python if needed, then installs the bridge in your Termux home. Adjust the command if you saved the file under another name or folder.

    Connect this app

    Enter the 8-digit pairing code shown in Termux. It can be used once within five minutes.

    3

    Prepare an agent

    Start with Terminal to check input and output. Install Codex, Claude Code or OpenCode in Termux and complete the required account authentication, provider connections and model setup.

    These configurations were checked on an Android 16 arm64 phone. Versions are reference versions, not automatic updates. A fresh installation on another phone still needs verification.

    Run each action in a new Termux terminal. Allow command access first; if Termux does not open, open it from its notification. Complete browser login yourself. Check the result in Termux. Command copying is also available below.

    Codex · Termux

    Use the community Termux package, not the standard Linux binary. This version requires Android 10+ and arm64. If Node.js and npm already work, skip the first command. Check the version, then sign in.

    pkg install nodejs-lts npm
    npm install -g @mmmbuto/codex-cli-termux@0.160.0-termux.3
    codex --version
    codex login
    Claude Code · Termux

    Claude 2.1.283 uses a separate Bibimer runtime. It requires arm64 Termux with glibc and ripgrep. Copy the repair command below and run it in Termux; it includes the Chat SDK. No setup file needs to be saved. If your CLI already works, prepare only the adapter.

    ~/.local/share/bibimer/claude-runtime/claude --version

    A successful version check does not confirm authentication. If your login has expired or you are signed out, run auth login below in Termux and finish signing in with the browser.

    ~/.local/share/bibimer/claude-runtime/claude auth status
    ~/.local/share/bibimer/claude-runtime/claude auth login

    Copy the bundled command and run it in Termux. No saved setup file or Downloads access is needed. This installs Node.js and the official Agent SDK; a working Claude CLI is required separately.

    OpenCode · Termux

    The checked OpenCode 1.17.13 uses the community OpenClaw Android setup: glibc, proot and a Bun binary wrapper. Installing the ordinary npm package alone does not reproduce it. Follow the Termux details for prerequisites and installation, then check the version and configure your provider connection.

    Choose a provider in Termux, then configure its API key or supported sign-in method. This sets up OpenCode’s connection to that provider.

    opencode --version
    opencode auth login
    Gemini CLI · Termux

    Gemini CLI 0.58.0 is also installed on the checked phone and requires Node.js 20+. Skip installation if it is already present. The Node commands below avoid a launcher path issue in the checked environment. Use Terminal to run it directly; Bibimer agent selection and structured Chat are not integrated. Sign-in and model responses still need verification.

    This opens Gemini CLI. Choose Sign in with Google, or type /auth if it is already signed in. Finish authentication in the browser. This does not add Gemini to Bibimer Chat.

    npm install -g @google/gemini-cli@0.58.0
    node "$(npm root -g)/@google/gemini-cli/bundle/gemini.js" --version
    node "$(npm root -g)/@google/gemini-cli/bundle/gemini.js"

    After setup in Termux, return to Bibimer and reconnect. If a bridge update requires a restart, finish active sessions first. Setup does not install all agents automatically.

    Finding a program does not confirm Android compatibility or account access. Check each agent's Termux installation and runtime requirements.

    When you come back

    Reopen the app to reconnect to a live bridge. If it is unavailable, run the start command in Termux. If Android stopped the environment, the previous process may no longer be recoverable.

    After installing an updated setup file, stop your active session and run the restart command in Termux.
