    GET YOUR PHONE READY

    A workspace on your phone.

    Follow these steps to install Termux and connect the app.

    1

    Install Termux

    Checking

    Termux stores your projects and runs development commands on this phone. Open it once after installation to finish its initial setup.

    Use the same distribution source for Termux and its plugins. Complete installation on the linked page and in Android's installer.

    2

    Set up the bridge

    Save the setup file as bibimer-setup.sh in your Download folder. It connects this app to Termux.

    Run these commands one at a time in Termux. Finish granting file access before running the installation command.

    termux-setup-storage
    bash ~/storage/downloads/bibimer-setup.sh

    The setup file installs Python if needed, then installs the bridge in your Termux home. Adjust the command if you saved the file under another name or folder.

    3

    Connect this app

    Enter the 8-digit pairing code shown in Termux. It can be used once within five minutes.

    4

    Prepare an agent

    Start with Terminal to check input and output. To use Codex or Claude Code, install a version that runs in Termux and complete any required sign-in.

    For Claude chat and import, export the latest setup file, then run the adapter setup command in Termux. Node.js and the official Agent SDK will be installed. A working Claude CLI is required separately.

    If Claude shows Needs repair, install a separate runtime. Requires arm64 Termux with glibc and ripgrep. Save the latest setup file first.

    Finding a program does not confirm Android compatibility or account access. Check each agent's Termux installation and runtime requirements.

    When you come back

    Reopen the app to reconnect to a live bridge. If it is unavailable, run the start command in Termux. If Android stopped the environment, the previous process may no longer be recoverable.

    After installing an updated setup file, stop your active session and run the restart command in Termux.
